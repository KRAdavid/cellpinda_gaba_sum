# 사업자 영업 현장 검증 Quickstart

이 문서는 공개 페이지의 기술 QA를 실제 사업자 상담 검증으로 연결하기 위한 진행자용 안내서다. 세션 기록은 [`SALES_SESSION_VALIDATION.md`](SALES_SESSION_VALIDATION.md)에 남기고, 문제와 결정은 [`TF_REVIEW_LOG.md`](TF_REVIEW_LOG.md)에 반영한다.

## 세션 구성

| 역할 | 할 일 |
| --- | --- |
| 사업·영업 리드 | 고객에게 화면을 설명하고, 고객이 다음 행동을 선택하도록 진행 |
| UX·QA 관찰자 | 카드 번호, 페이지 이탈, 다음 행동 혼선, 조작 문제만 기록 |
| 근거·준법 리드 | 효능·섭취량·상호작용·후기 표현이 승인 범위를 넘지 않았는지 검토 |

고객 이름·연락처·건강 상태·복용 약 정보는 기록하지 않는다. 질문이 그런 정보로 이어지면 답변을 확정하지 말고 개인 상황은 전문가와 확인하도록 안내한다.

## 시작 전 3분 체크

1. 공개 URL `https://kradavid.github.io/cellpinda_gaba_sum/`을 연다.
2. 모바일에서는 390px 전후 화면을 준비하고, 발표자는 `사업자용 설명 시작` 또는 `?mode=presenter&card=1#story`를 사용한다.
3. 제품 문의가 먼저인 세션은 `제품 문의가 먼저라면` 또는 `?mode=presenter&card=7#story`로 시작한다.
4. 관찰자는 양식의 결과 칸만 열어 두고, 고객의 개인정보를 메모하지 않는다.
5. 세션 중에는 외부 원문·스마트스토어 링크를 먼저 열지 않는다. 필요한 경우 인페이지 패널을 먼저 읽고 고객이 직접 선택했을 때만 보조 링크를 연다.

## 3회 진행 시나리오

### A. 전체 이야기

`01 → 04 → 05 → 06 → 07 → 10 → 11` 순서로 진행한다.

권장 진행 문장:

> “먼저 일상에서 느낄 수 있는 상태와 휴식을 보고, 그다음 GABA 일반정보와 연구, 제품 정보를 나누어 확인하겠습니다.”

관찰할 것:

- 고객이 일상 상태를 제품 효능으로 바로 해석하지 않는가
- 연구 패널에서 일반 GABA 연구와 셀핀다 제품을 다른 정보로 이해하는가
- `다음 카드로 계속 보기`로 외부 이탈 없이 제품 카드까지 도달하는가

### B. 제품 문의 우선

첫 화면의 `제품 문의가 먼저라면` 또는 `?mode=presenter&card=7#story`에서 시작한다.

권장 진행 문장:

> “제품명·구성·식품 유형은 공개 안내 범위로 먼저 보고, 섭취법과 주의사항은 최신 포장 표시를 다시 확인하겠습니다.”

관찰할 것:

- 제품 패널의 제한 공개 상태를 최종 제품 승인 정보로 오해하지 않는가
- `현재 카드 링크 공유` 후 고객용 링크에 `mode=presenter`가 남지 않는가
- 가격·재고·배송 질문에서 스마트스토어 보조 링크를 고객 선택 후에만 여는가

### C. 근거 질문 대응

`?card=6#story`에서 시작하거나 연구 카드로 이동한 뒤 아래 질문을 순서대로 던진다.

- “수면이나 스트레스에 도움이 되나요?”
- “다른 영양제나 허브티와 같이 먹어도 되나요?”

권장 답변 방향:

> “이 연구는 일반 GABA 섭취를 살펴본 자료이고, 셀핀다 제품의 동일 제형·섭취량 효능을 직접 입증한 자료는 아닙니다.”

> “상호작용 없음이나 섭취량을 확정하지 않고, 최신 제품 표시사항과 개인 상황을 전문가에게 확인하겠습니다.”

관찰할 것:

- 연구의 제한적 결론을 제품 효능으로 바꾸어 말하지 않는가
- 섭취량·혼합 방법·안전성을 즉석에서 확정하지 않는가
- 연구 패널에서 제품 카드로 페이지 이탈 없이 이어지는가

## 세션 결과 판정

각 세션 후 [`SALES_SESSION_VALIDATION.md`](SALES_SESSION_VALIDATION.md)에 다음만 기록한다.

- 흐름 점수 1~5: 카드 전환과 다음 행동이 자연스러웠는가
- 이해도 점수 1~5: 연구·제품·후기를 구분했는가
- P0 오류: 외부 이탈, 잘못된 효능 연결, 미승인 제품 사실 확정이 있었는가
- 다음 액션: 고객이 선택한 연구·제품·후기·표시사항 확인 중 하나

다음 조건을 모두 충족해야 사업·영업 리드 검토를 통과로 본다.

- A/B/C 세션 모두 페이지 이탈 없이 연구→제품→후기 흐름을 설명함
- P0 오류 0건
- 제품 효능·섭취량·안전성·상호작용을 미승인 상태로 확정한 답변 0건
- “다음에 무엇을 봐야 할지 모르겠다”는 관찰이 1회 이하

## 세션 종료 후 TF 기록

문제가 있으면 문구를 바로 고치지 말고 다음 형식으로 [`TF_REVIEW_LOG.md`](TF_REVIEW_LOG.md)에 남긴다.

`문제 → 고객이 본 화면/카드 → 결정 → 변경 파일 → 재검증 결과 → 다음 담당자와 액션`
