## 경계

AI-OPS 자동 구성은 초안 작성·정리·QA·후보 큐잉을 시작한다. 실명 배정, 과학·의학 판단, 영상 권리, `PUBLISH_GENERAL`, 실제 소비자·실기기 결과, 최종 배포 승인은 대신하지 않는다. 이 경계를 넘는 입력이 없으면 상태를 `HOLD`로 유지한다.

운영 화면에서는 발표자 URL의 `운영 보드`에서 같은 설정을 확인할 수 있다. 브라우저의 팀 업무 배정 입력은 회의용 로컬 초안이며 공식 역할표나 공개 승인 상태를 바꾸지 않는다.
