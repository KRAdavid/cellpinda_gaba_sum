인페이지 흐름 안내 공개 배포 확인: `0de78db`의 [Pages run 35605454516](https://github.com/KRAdavid/cellpinda_gaba_sum/actions/runs/35605454516)에서 TF 문서 게이트·번들 가드·Pages 배포가 성공했다. 공개 JS 자산과 HTTP 200을 확인했으며, 실제 외부 링크 동작은 사용자가 명시적으로 선택하는 보조 경로로 유지한다.

공유 확인 문구 보완: 사업자가 발표자 모드에서 링크를 복사한 뒤에도 고객에게 전달할 링크의 상태를 즉시 알 수 있도록 성공 메시지를 `고객용 링크`와 `발표자 모드 제외`로 명시했다. 영업 가이드와 카드 공유 QA도 같은 표현으로 맞추며, 링크 자체에서 발표자 모드가 제거되는 기존 동작은 유지한다.

## 의사결정 원칙

1. 관심은 소비자가 공감할 수 있는 일상 장면에서 만든다.
2. 성분 소개는 일반정보로 시작하고 제품 효능으로 건너뛰지 않는다.
3. 연구·제품 표시사항·구매자 후기는 서로 다른 정보로 표시한다.
