추가 준법 결정: `일상 상태 → 휴식 → GABA` 흐름의 암시효능 가능성을 낮추기 위해 GABA의 생리 기능 설명을 제거하고, 일반 GABA 문헌고찰의 제한적 결론(스트레스 근거 제한적·수면 근거 매우 제한적)과 연구-제품 전환 문구를 추가했다. 활용 TIP의 미확인 혼합 예시도 삭제하고 제품 표시사항 확인으로 통일했다.

외부 판매 페이지 재확인: 2026-09-21 읽기 전용 요청에서 스마트스토어 상품 URL은 HTTP 429를 반환했고, 웹 도구에서도 접근할 수 없었다. 품절·판매중단으로 해석하지 않으며, 최신 라벨·가격·재고·배송 정보는 공개 문구에 추가하지 않는다.

제품 증거 재확인: 관련 공식 저장소의 B2 검증 패킷에서 완제품 포장 후보와 30포·기타가공품 표시 신호를 확인했다. 패킷은 `VERIFYING` 상태이며 현행 판매 SKU·최종 인쇄 승인본·표시 책임자 승인이 남아 있으므로 공개 사이트의 보수적 문구와 이미지 미사용을 유지한다. 다음 액션은 제품 책임자의 최종본 대조다.

영업 UX 개선: 발표 모드 안에 카드별 `발표자용 설명 포인트`를 접었다 펼칠 수 있게 추가했다. 고객 화면의 기본 흐름은 유지하면서, 설명자는 연구·제품·후기 경계를 지키는 승인 문장을 같은 화면에서 확인할 수 있다.

시각 QA 보완: 설명 포인트가 열린 모바일 발표 모드에서 상단이 잘리지 않도록 자동 카드 스크롤을 제거하고 발표 영역을 상단 시작으로 고정했다. 밝은 제품 카드의 제목·본문 대비도 명시적으로 보정했으며, 390px 캡처에서 확인했다.

릴리스 QA 자동화: `scripts/qa-public.mjs`를 추가해 빌드 번들의 필수 경계 문구와 발표 기능 존재 여부, 금지 표현·검증되지 않은 제품 이미지·기존 공식 사이트 URL의 혼입 여부를 자동 검사한다. `pnpm run qa:public`과 Pages workflow에서 실행한다.

상호작용 QA 개선: `pnpm run qa:interaction`에서 연구 패널의 `다음 카드로 계속 보기` 직후 이전 카드 진행률로 되돌아가는 경합을 재현했다. 프로그램 이동 목표 카드가 65% 이상 보일 때까지 IntersectionObserver의 이전 값을 무시하도록 수정했고, 발표 딥링크·메모·Escape·연구 패널·제품 패널 흐름을 다시 통과시켰다.

마감 품질 보완: 브라우저 콘솔의 favicon 404를 제거하기 위해 Cellpinda GABA 전용 SVG favicon을 추가하고, 번들 QA에서 링크와 실제 자산 존재를 함께 검사한다.

발표 접근성 개선: `?mode=presenter&card=N#story`로 발표 모드와 카드 위치를 바로 열 수 있게 했다. 발표 중 카드 링크를 복사하면 `mode=presenter`가 유지되고, `Esc`로 종료하면 일반 카드 URL로 정리된다.

영업 공유 UX 개선: `현재 카드 링크 공유` 버튼이 모바일의 기본 공유 메뉴를 우선 사용하고, 지원하지 않는 환경이나 권한 오류에서는 클립보드·선택 복사로 대체되도록 구현했다. 고객에게 전달하는 링크에는 현재 카드 번호와 `#story` 위치만 유지하고 `mode=presenter`는 제거해 발표자 메모·컨트롤이 노출되지 않게 했으며, 공개 URL 상호작용 QA에서 검증했다.

TF 재검토 — 근거·준법: 생활 속 휴식 카드에 특정 성분·제품 효과와 무관하다는 문장을 추가하고, 제품 패널에는 최신 포장·판매 SKU 대조 전의 제한 공개 상태를, 후기 패널에는 사용권 확인 전 재게시 금지를 명시했다. 변경 파일은 `src/App.tsx`, `src/styles.css`, `scripts/qa-public.mjs`이며 번들 QA에서 세 경계 문구를 필수 항목으로 검사한다. 최종 전체 광고 인상 승인은 계속 HOLD다.

TF 재검토 — 접근성·QA: 연구 딥링크가 `#story`를 카드 값에 잘못 포함하던 테스트를 실제 `?card=6#story`로 고치고, 패널의 `다음 카드로 계속 보기`가 이전 트리거에 포커스를 돌려보내던 문제를 새 카드 컨트롤로 이동하도록 수정했다. 공유 API 실패·클립보드 실패·선택 복사 fallback과 제품 확인 상태를 상호작용 QA에서 검증했으며, 로컬 및 공개 URL 테스트가 모두 통과했다.

QA 안정화: 공개 배포 직후 Chrome이 이전 번들을 사용할 수 있어 상호작용 QA에서 브라우저 캐시를 비우고, 딥링크 전환은 고정 시간 대신 목표 진행률을 확인한 뒤 다음 단계로 진행하도록 보강했다. 이로써 배포 직후의 오래된 자산·페이지 전환 타이밍 오판을 줄인다.

영업 진입 UX 개선: 첫 화면에 `제품 문의부터 보기` 버튼을 추가해 사업자가 URL을 외우지 않고도 07번 제품 카드부터 시작할 수 있게 했다. 전체 설명 진입과 제품 문의 진입을 분리하고, 공개 URL 상호작용 QA에서 07번 카드 도달을 확인했다.

실제 영업 검증 준비: 세션 양식에 전체 이야기(A), 제품 문의 우선(B), 근거 질문 대응(C) 세 시나리오를 추가했다. 세션이 실제로 기록되기 전에는 영업 적합성을 PASS로 바꾸지 않으며, 관찰 기록은 카드 번호·표현·이탈 여부·다음 행동만 남기도록 개인정보·건강정보 수집을 금지한다.

연구→제품→후기 흐름 QA 보강: 공개 상호작용 QA에 10번 후기 카드의 인페이지 패널, 개인 경험·효능 비증명 경계, 원문·이미지 사용권 확인 전 재게시 금지 상태를 추가했다. 연구·제품·후기 세 단계 모두 외부 링크를 선택하기 전 현재 페이지 안에서 확인되는지 검증한다.

QA 격리 보완: 상호작용 QA가 직전 브라우저의 발표 모드 URL을 물려받지 않도록 시작 시 항상 공개 기본 URL로 이동하게 했다. 일반 소비자 화면에 발표자 보조 정보가 숨겨지는 조건도 자동 검사하며, 재실행 순서와 무관하게 전체 상호작용 QA가 통과했다.

종료 카드 흐름 개선: 마지막 카드의 단일 제품 링크를 연구·제품·후기 세 가지 인페이지 선택지로 확장했다. 고객이 상담 마지막에 원하는 자료를 직접 고를 수 있고, 어느 선택도 즉시 외부 페이지로 이탈하지 않는다. 공개 상호작용 QA에서 세 버튼의 존재와 연구 패널 진입을 확인했다.

## 의사결정 원칙

1. 관심은 소비자가 공감할 수 있는 일상 장면에서 만든다.
2. 성분 소개는 일반정보로 시작하고 제품 효능으로 건너뛰지 않는다.
3. 연구·제품 표시사항·구매자 후기는 서로 다른 정보로 표시한다.
4. 외부 링크는 설명 흐름을 끝낸 뒤 사용자가 직접 선택한다.
5. 확인되지 않은 최신 라벨·섭취량·주의사항·안전성·후기 원문은 공개 문구로 확정하지 않는다.

- 최소 3회의 실제 사업자 상담에서 카드 흐름과 다음 행동이 막힘없이 이어진다.
