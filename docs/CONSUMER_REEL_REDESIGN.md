# 소비자 GABA 리더 전면 개선안

## 결정

소비자 공개 화면의 기본 단위를 카드 목록이 아니라 **한 화면 한 메시지의 세로 리더**로 사용한다. 첫 화면에서 GABA를 모르는 사람이 바로 일상 장면을 읽고, 화면 안에서 다음 장면으로 넘긴다.

## 사용자 흐름

1. `01 / 08` 진행 상태와 첫 일상 메시지를 즉시 보여준다.
2. 우측 세로 진행 레일에서 원하는 장면으로 바로 이동한다.
3. 다음 장면 버튼, 마우스 휠, 위·아래 키, 모바일 스와이프로 한 장면씩 이동한다.
4. 연구 확인은 같은 페이지의 인페이지 패널에서 먼저 읽는다.
5. 마지막 장면에서만 별도 영상 섹션으로 이어진다.
6. 영상 후보는 한 편씩 넘겨 보고, 원문 플레이어는 사용자가 누른 뒤 페이지 안에서 재생한다.

## 화면 원칙

- 카드 테두리·카드 그리드·긴 목차를 제거하고 밝은 종이색의 열린 편집 캔버스를 사용한다.
- 큰 제목 하나, 짧은 일상 설명 하나, 다음 행동 하나만 기본 화면에 둔다.
- 좌측 장면 레일은 현재 위치와 장면 이름을 알려주고, 장면 이동을 위한 직접 조작으로도 사용한다. 모바일에서는 상단 진행선으로 축약한다.
- `근거는 조건까지`를 고정해 연구 결과가 제품 효능으로 확장되지 않도록 한다.
- 제품명·구매·후기·개인별 섭취 판단은 소비자 리더와 영상 후보 요약에서 제외한다.

## 사업자 사용성

발표자 화면은 별도 `?mode=presenter` 경로에서 기존 영상 DB·감리 패널·TF 운영 보드를 유지한다. 소비자 화면에는 발표자 메모와 감리 대장을 노출하지 않고, 현재 장면 공유만 제공한다.

## 수용 기준

- 모바일 320·390px에서 한 번에 한 장면만 보이고 수평 overflow가 없다.
- 버튼·휠·키보드·모바일 스와이프 중 하나로 다음 장면에 도달한다.
- 현재 장면 링크는 `card` 값과 `#story`를 유지하고 발표자 모드를 포함하지 않는다.
- 연구 패널은 외부 원문을 열기 전에 현재 페이지 안에서 조건·한계를 보여준다.
- 영상 후보는 원문·자막·화자·권리 감리 전 일반 GABA 근거 자료로 표시하지 않는다.
- 제품·후기·판매 문구가 소비자 번들에 유입되면 공개 QA가 실패한다.
