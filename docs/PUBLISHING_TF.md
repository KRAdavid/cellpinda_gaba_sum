# 공개용 GABA 페이지 퍼블리싱 TF

## 목표

`cellpinda_gaba_sum`은 기존 `cellpinda_GABA` 공식 배포 사이트와 분리된 소비자용 소개 페이지다. 영업 담당자가 고객에게 화면을 넘겨 보여주기 쉽고, 고객은 외부 페이지로 빠져나가지 않은 채 GABA 이야기의 흐름을 끝까지 따라갈 수 있도록 운영한다.

## TF 운영 리듬과 결정권

퍼블리싱 준비 기간에는 주 1회 30분 리뷰를 열고, 공개 문구·영업 흐름·근거 경계·실기기 동작 중 하나라도 바뀌면 다음 정기 회의까지 기다리지 않고 해당 담당자가 비동기 검토를 요청한다. 모든 검토는 `문제 → 결정 → 변경 파일 → 검증 결과 → 다음 액션` 형식으로 `TF_REVIEW_LOG.md`에 남긴다.

| 결정 항목 | 최종 확인 담당 | 보류 기준 |
| --- | --- | --- |
| 연구·효능·안전성 표현 | 근거·준법 리드 | 1차 근거 또는 최신 표시사항이 없으면 공개 문구를 확정하지 않음 |

### 정식 공개 실행 보드

아래 표는 상태 보고가 아니라 다음 증거를 만드는 작업 보드다. `HOLD`는 작업 중단이 아니라, 해당 담당자가 종료 증거를 만들기 전까지 공개 승인을 보류한다는 뜻이다. 기술 QA가 통과해도 현장·제품·권리 증거가 없으면 상태를 바꾸지 않는다.

| 워크스트림 | 목적 | 현재 상태 | 산출물 | 종료 조건 | 담당 | 다음 액션 |
| --- | --- | --- | --- | --- | --- | --- |
| 공개 흐름·영업 UX | 고객이 페이지를 떠나지 않고 카드 이야기를 끝까지 따라가게 함 | 기술 PASS / 현장 HOLD | 공개 카드 흐름, 발표 모드, 고객용 링크, A/B/C 세션 기록 | A/B/C 각 1회에서 무이탈 흐름 완주, 다음 행동 명확도 평균 4점 이상, P0 0건 | 사업·영업 리드 + 소비자 UX·카피 리드 | 실제 담당자 3명을 섭외하고 `SALES_SESSION_VALIDATION.md`에 관찰 결과 기록 |

## 이번 의사결정

### 문제

카드에서 `원문 보기`, `제품 정보 보기`, `후기 보기`를 바로 외부 링크로 열면 사용자가 현재 이야기에서 이탈한다. 특히 모바일에서는 돌아오기 어렵고, 영업 담당자가 설명 흐름을 다시 잡아야 한다.

### 결정

카드의 정보 버튼은 먼저 현재 페이지 안의 정보 패널을 연다.

- 연구 카드: 연구를 읽는 방법, 참여자·섭취량·기간·비교 조건 확인
- 제품 카드: 제품 구성·표시사항·판매 정보 확인 순서
- 후기 카드: 개인 경험과 제품 정보의 구분 기준
- 원문·스마트스토어 링크: 패널 하단의 접힌 `필요할 때만 확인` 영역 안에서만 제공
- `다음 카드로 계속 보기`: 패널을 닫고 다음 카드로 이동해 흐름 유지
- 소비자 화면의 `다음 카드`: 스와이프를 사용하지 않아도 한 번 눌러 다음 장으로 이어지는 명시적 기본 행동
- 소비자 화면의 공유·발표 기능: `더 보기` 안에 접어 카드 이야기의 기본 주목도를 유지
- 패널 안에 현재 페이지 흐름이 유지된다는 안내를 표시해 외부 링크가 필수 경로가 아님을 명확히 함

발표 모드에서는 카드별로 `고객에게 물어보기`와 `이어서 말할 때`를 분리해 보여준다. 이는 사업자가 즉흥적으로 효능을 덧붙이지 않고 고객 질문과 근거 경계를 함께 유지하도록 돕는 발표자 전용 보조 정보이며, 소비자용 일반 카드에는 노출하지 않는다.

발표자 질문 대응 전달성도 같은 원칙으로 관리한다. `자주 묻는 질문에 답하기`는 기본 닫힘으로 두고, 각 항목의 `답변 복사`는 승인된 보류 문장을 페이지 안에서 바로 전달할 때만 사용한다. 복사 기능은 소비자 화면에 노출하지 않으며, 문장을 복사한 뒤에도 발표 카드 흐름을 유지한다.

### 카드 단계 안내 보완

카드 번호와 점만 보이면 사업자가 현재 설명 위치를 다시 말해야 하고, 고객은 연구·제품·후기 사이의 이동 순서를 놓칠 수 있다. 카드 레일 위에 `일상 상태 → 휴식 → 성분 일반정보 → 일반 연구 → 제품 정보 → 생활 루틴 → 후기·마무리`를 표시하고 현재 단계만 강조해, 페이지를 떠나지 않고도 전체 이야기의 위치를 이해하도록 했다. 이 안내는 새로운 효능이나 제품 사실을 추가하지 않는다.
