# 공개용 GABA 페이지 퍼블리싱 TF

## 현재 목표

`cellpinda_gaba_sum`은 기존 `cellpinda_GABA` 공식 배포 사이트와 분리된 일반 GABA 교육 페이지다. 목표는 GABA를 모르는 소비자가 과학적 근거와 감리된 권위 영상을 한 장씩 이해하도록 돕는 것이다.

제품명·가격·구성·섭취량·후기·판매 링크는 이 공개 교육본의 범위에 포함하지 않는다.

## 반복 운영 순서

1. 매일 후보를 채널 RSS·Shorts 페이지·유사 검색어에서 수집한다.
2. 새 후보는 `PENDING_REVIEW`로만 기록한다.
3. VIDEO가 원문·자막·화자를 확인한다.
4. SCIENCE/MEDICAL이 일반 생리·경구 GABA 연구·수면·스트레스·치료 주장을 분리한다.
5. RIGHTS가 사용 방식을 확인한다.
6. PM/UX가 공개 문장과 사업자 설명 문장을 정리한다.
7. 사람 승인된 일반 교육 영상만 `PUBLISH_GENERAL`로 바꾼다.

## 공개 요청 전달 단계

발표자 영상 DB의 `공개 요청 패킷 저장`은 공식 DB나 Pages를 즉시 변경하지 않는다. 국내 영상 중 다음 조건을 모두 충족한 초안만 JSON에 포함한다.

- 5개 감리 항목: 원문·영상, 자막·대본, 화자·자격, 권리·사용, 주장 범위·연구 구분
- 담당자·타임코드·확인한 발언·자막 발췌 입력
- 결정 초안 `PUBLISH_GENERAL`

패킷은 PM·SCIENCE/MEDICAL·RIGHTS가 마지막으로 공개 문장과 권리를 확인한 뒤 사람이 `gabaVideos.ts`와 공개 배포본에 반영하기 위한 인수인계 자료다. 자동 모니터 후보와 미완료 초안은 패킷에 포함되지 않으며, 승인 없는 자동 공개는 계속 0건으로 유지한다.

## 현재 수용 기준

- 소비자 화면은 1화면 1메시지로 읽히고 하단의 다음 메시지 안내가 기본 행동이어야 한다.
- 연구 패널은 외부 원문보다 먼저 일반 설명과 조건을 보여주고, 영상은 피드 뒤 별도 요약 섹션에서 원문으로 이어져야 한다.
- `일반 GABA 연구`가 특정 제품 효능으로 연결되지 않아야 한다.
- 자동 모니터가 새로 발견한 `PENDING_REVIEW` 후보는 소비자 화면에 노출하지 않는다. 단, 사용자가 직접 제공한 국내 Shorts는 별도 `영상 검토 후보` 영역에서만 중립 요약·인물 확인·원문 링크로 소개할 수 있으며, `PUBLISH_GENERAL` 권위 영상이나 과학적 근거로 표시하지 않는다.
- 실제 iOS·Android와 A/B/C 세션 증거가 없으면 현장 PASS로 표시하지 않는다.

상세 판정은 [`GOAL_ACCEPTANCE_MATRIX.md`](GOAL_ACCEPTANCE_MATRIX.md), 영상 운영은 [`GABA_VIDEO_DAILY_MONITOR.md`](GABA_VIDEO_DAILY_MONITOR.md), 사업자 사용은 [`GENERAL_GABA_OPERATOR_GUIDE.md`](GENERAL_GABA_OPERATOR_GUIDE.md)를 기준으로 한다.
