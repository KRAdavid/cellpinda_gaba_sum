# 공개용 GABA 페이지 퍼블리싱 TF

## 목표

`cellpinda_gaba_sum`은 기존 `cellpinda_GABA` 공식 배포 사이트와 분리된 소비자용 소개 페이지다. 영업 담당자가 고객에게 화면을 넘겨 보여주기 쉽고, 고객은 외부 페이지로 빠져나가지 않은 채 GABA 이야기의 흐름을 끝까지 따라갈 수 있도록 운영한다.

## 이번 의사결정

### 문제

카드에서 `원문 보기`, `제품 정보 보기`, `후기 보기`를 바로 외부 링크로 열면 사용자가 현재 이야기에서 이탈한다. 특히 모바일에서는 돌아오기 어렵고, 영업 담당자가 설명 흐름을 다시 잡아야 한다.

### 결정

카드의 정보 버튼은 먼저 현재 페이지 안의 정보 패널을 연다.

- 연구 카드: 연구를 읽는 방법, 참여자·섭취량·기간·비교 조건 확인
- 제품 카드: 제품 구성·표시사항·판매 정보 확인 순서
- 후기 카드: 개인 경험과 제품 정보의 구분 기준
- 원문·스마트스토어 링크: 패널 하단의 보조 링크로만 제공
- `다음 카드로 계속 보기`: 패널을 닫고 다음 카드로 이동해 흐름 유지
- 패널 안에 현재 페이지 흐름이 유지된다는 안내를 표시해 외부 링크가 필수 경로가 아님을 명확히 함

발표 모드에서는 카드별로 `고객에게 물어보기`와 `이어서 말할 때`를 분리해 보여준다. 이는 사업자가 즉흥적으로 효능을 덧붙이지 않고 고객 질문과 근거 경계를 함께 유지하도록 돕는 발표자 전용 보조 정보이며, 소비자용 일반 카드에는 노출하지 않는다.

### 카드 단계 안내 보완

카드 번호와 점만 보이면 사업자가 현재 설명 위치를 다시 말해야 하고, 고객은 연구·제품·후기 사이의 이동 순서를 놓칠 수 있다. 카드 레일 위에 `일상 상태 → 휴식 → 성분 일반정보 → 일반 연구 → 제품 정보 → 생활 루틴 → 후기·마무리`를 표시하고 현재 단계만 강조해, 페이지를 떠나지 않고도 전체 이야기의 위치를 이해하도록 했다. 이 안내는 새로운 효능이나 제품 사실을 추가하지 않는다.

## 공개 전 수용 기준

1. 카드 버튼을 눌러도 현재 페이지가 외부 URL로 이동하지 않는다.
2. 정보 패널에서 핵심 내용을 읽은 뒤 다음 카드로 이어갈 수 있다.
3. 연구 패널에 일반 GABA 연구라는 표시와 셀핀다 제품 효능 직접 입증이 아니라는 경계가 있다.
4. 제품 패널은 제품 표시사항·스마트스토어 확인을 안내하며 연구 결과처럼 말하지 않는다.
5. 후기 패널은 개인 경험임을 표시하며 효능 근거로 표현하지 않는다.
6. 모바일 390px 전후에서 패널이 화면 밖으로 잘리지 않는다.
7. `Escape`, 닫기 버튼, 패널 바깥 클릭으로 패널을 닫을 수 있다.
8. 원문·제품·후기 외부 링크는 사용자가 명시적으로 선택한 경우에만 새 탭에서 열린다.
9. 발표 모드에서는 한 번에 한 카드만 보이고, 진행률·이전/다음·Escape 종료가 동작한다.
10. 기존 `cellpinda_GABA` 배포 주소와 새 `cellpinda_gaba_sum` 공개 주소가 화면·저장소·배포 설정에서 혼동되지 않는다.
11. 전체 카드 흐름을 하나의 광고 인상으로 읽었을 때, 일상 상태·휴식·GABA·연구·제품 사이에 승인되지 않은 효능 연결이 없어야 한다.

## 제품 정보 게이트

현재 공개 페이지에 표시하는 제품 사실은 보수적으로 제한한다.

- 공개 표시: `셀핀다 가바 1500`, `30포 구성`, `기타가공품`
- 제품 이미지: 최신 로트 표시 검증 전까지 공개 페이지에서 사용하지 않음
- 판매 정보: 가격·재고·배송은 스마트스토어에서 확인
- 보류: 최신 로트의 후면 표시, 섭취법·보관법·주의사항의 최종 승인, 원재료·함량의 제품별 확정, 안전성·상호작용 표현
- 후속 담당: 제품 책임자와 근거·준법 리드가 최신 표시사항을 대조한 뒤 공개 범위를 갱신

2026-09-21 증거 재확인: 공식 저장소의 [B2 완제품 표시사항 검증 패킷](https://github.com/KRAdavid/cellpinda_GABA/blob/main/docs/B2_MATERIAL_VERIFICATION_20260911.md)에서 30포·기타가공품·포장 표시 후보를 확인했다. 패킷 상태가 `VERIFYING`이고 현행 판매 SKU·최종 인쇄 승인본·표시 책임자 승인이 남아 있으므로, 이번 공개본에는 새 수치·섭취법·제품 이미지를 추가하지 않는다.

- `04`: 성분을 소개하기 전에 화면을 내려놓고 물을 마시거나 창밖을 보는 생활 속 휴식을 제안한다.
- `05`: GABA가 갑자기 제품 효능처럼 등장하지 않도록 일반 성분정보부터 살펴본다고 명시하고, 바로 연구 조건을 구분한다.
- `06~11`: 일반 연구·제품 표시사항·구매자 후기를 서로 다른 정보로 유지한다.
- 카드 레일에는 설명 단계만 추가해, 고객이 현재 위치를 놓치지 않고 다음 카드로 계속 이동할 수 있게 한다.

검토 결론은 “관심은 일상 장면에서 만들고, 제품 설명은 근거와 표시사항을 확인한 뒤 별도로 진행한다”이다.
