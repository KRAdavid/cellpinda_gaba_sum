# 공개용 GABA 퍼블리싱 TF 팀 초대·킥오프 패킷

이 문서는 실제 담당자를 모으고 첫 30분 회의를 잡기 위한 전달용 문서다. 역할 정의와 기술 QA가 끝났다는 뜻이 아니며, 아래 사람 입력과 현장 증거가 생기기 전에는 최종 사업·준법 승인을 표시하지 않는다.

## 초대 메시지

아래 블록을 그대로 복사해 내부 메신저나 이메일로 전달한다.

> 셀핀다 GABA 공개 소비자 안내 페이지를 기존 공식 배포 사이트와 분리해 운영하기 위한 퍼블리싱 TF를 시작합니다. 목표는 연구·제품·후기를 외부 페이지로 보내지 않고 한 장씩 이어 보여 주면서, 사업자가 고객 앞에서 설명하기 쉬운 흐름을 만드는 것입니다.
>
> 첫 회의는 30분입니다. 기술 QA 통과 여부만 보지 않고, 실제 담당자·제품 표시사항·후기 권리·사업자 현장 검증을 각각 분리해 결정합니다. 고객의 이름·연락처·건강 상태·복용 약은 기록하지 않습니다.
>
> 참석 가능 여부와 맡을 수 있는 역할을 아래 회신 양식으로 알려 주세요.

## 핵심 역할과 결정 범위

| ID | 역할 | 첫 회의에서 답할 질문 | 반드시 내야 할 첫 산출물 |
| --- | --- | --- | --- |
| PM | TF 리드·PM | 이번 회의에서 결정할 것과 보류할 것을 분리했는가? | 회의 안건·보류 기준·다음 검토일 |
| SALES | 사업·영업 리드 | 고객이 지금 무엇을 보고 다음에 무엇을 해야 하는지 바로 아는가? | A/B/C 세션 진행자·관찰자·일정 |
| UX | 소비자 UX·카피 리드 | 카드 하나에 메시지 하나이며 일상 용어로 읽히는가? | 카드 흐름·CTA·혼선 후보 |
| EVIDENCE | 근거·준법 리드 | 일반 GABA 연구가 제품 효능처럼 읽히지 않는가? | 전체 광고 인상 검토·보류 문장 |
| PRODUCT | 제품 책임자·표시 승인자 | 제품명·SKU·구성·식품 유형·로트가 최신 1차 자료와 맞는가? | 제품 사실 등록부·승인 범위 |
| QA | 릴리스 QA 리드 | 공개 자산·실기기·공유 링크가 같은 버전인가? | 기기 계획·QA 캡처·이슈 목록 |

프론트엔드·접근성, 마케팅·소비자 심리, 브랜드·전환 경험, 시각화, 데이터·판매처 운영 역할은 관련 안건의 실행 협력·사전 검토자로 참여한다. `PRODUCT`와 `EVIDENCE`의 승인 판단은 구현자·영업 진행자와 분리한다.

## 첫 회의 안건

첫 회의에는 아래 논점 중 1~2개만 올린다. 새 카피를 많이 만드는 회의가 아니라 종료 증거와 담당자를 정하는 회의다.

1. `UX-03` — 첫 화면에서 전체 흐름과 사업자·제품 진입의 위계를 바로 이해하는가?
2. `SALES-01` — 제품 문의 후 제품 안내·다음 카드·외부 자료의 선택을 구분하는가?
3. `SALES-04` — 근거 질문이 나오면 발표자가 `근거부터 설명`으로 06번 카드에 바로 진입하는가?

현재 공개 페이지의 기술 기준은 `기술 PASS / 현장 HOLD`다. 실제 A/B/C 세션에서 다음 행동 명확도는 **각 세션 4점 이상**, 외부 선행 이탈 0건, P0 오류 0건이어야 한다. 평균 점수만으로 통과시키지 않는다.

## 30분 진행

| 시간 | 진행 | 결과물 |
| --- | --- | --- |
| 0~3분 | 공개 URL·현재 커밋·HOLD 게이트 확인 | 오늘 결정할 논점 1~2개 |
| 3~10분 | 소비자 흐름·발표 모드 직접 확인 | 가장 큰 고객 혼선 1개 |
| 10~18분 | A/B/C 시나리오와 `다음 카드`·인페이지 패널 검토 | 적용/관찰/HOLD 중 하나 |
| 18~24분 | 제품·근거·후기·실기기 증거 확인 | 필요한 자료와 제출자 |
| 24~30분 | 결정 대장 갱신 | 담당자·기한·종료 조건·다음 검토일 |

## 회신 양식

```text
이름 또는 내부 식별자:
희망 역할 / 백업 역할:
참석 가능 시간:
A 시나리오 설명자 / 관찰자:
B 시나리오 설명자 / 관찰자:
C 시나리오 설명자 / 관찰자:
제품 사실 자료 제출 가능 여부:
후기 권리 자료 제출 가능 여부:
iOS·Android 확인 가능 기기:
```

회신 내용은 [`TF_KICKOFF_INPUT.md`](TF_KICKOFF_INPUT.md)에 옮기고, 확정된 담당자·백업·결정권은 [`TF_ROSTER.md`](TF_ROSTER.md)에 기록한다. 회의 결과는 [`TF_DECISION_REGISTER.md`](TF_DECISION_REGISTER.md)와 [`TF_REVIEW_LOG.md`](TF_REVIEW_LOG.md)에 남긴다.

## 승인 경계

- 일반 GABA 연구를 셀핀다 제품의 동일 제형·섭취량 효능으로 바꾸어 말하지 않는다.
- 최신 포장·로트 확인 전 제품명·구성·섭취량·주의사항을 확정 범위로 넓히지 않는다.
- 후기 원문·이미지는 권리·작성 맥락·경제적 이해관계를 확인하기 전 재게시하지 않는다.
- 고객 개인정보와 건강정보를 세션 기록에 남기지 않는다.
- 외부 원문·판매처는 인페이지 패널을 읽은 뒤 고객이 직접 선택할 때만 연다.
