## 현재 운영 게이트

- 인간 역할 배정: `0/7`
- 출처 사람 검토: `0/5`
- 출처 검토 초안: `0/5` 완료(브라우저 로컬 초안이며 공식 `HUMAN_REVIEWED` 상태와 별개)
- 등록 영상 공개 승인: `DB 승인 이력 2/12(해외 AUTH) · 국내 공개 승인 0/10`
- 공개 연결 게이트: 국내 `PUBLISH_GENERAL` 승인분만 소비자 `검토 완료 영상` 영역에 노출하며 현재 승인 0건이라 영역은 숨김
- 첫 회의 입력: 필요
- 실제 iOS·Android: 미검증
- A/B/C 현장 세션: 미실시
- 영상 검토 집중도: 7개 후보를 큰 카드로 동시에 쌓지 않고 현재 영상 1건과 compact 인덱스·이전/다음 이동으로 제공
- 권위 후보 큐: 5건은 `전문가 표현 감지 · 자격 미확인` 또는 `권위 검색 발견 · 자격 미확인`으로 분리된 발견 목록이며 의사·과학자 자격 또는 영상 타당성 승인 목록이 아님
- 공개 영상 경계: 자동 수집 `PENDING_REVIEW` 후보는 비공개이며, 사용자가 직접 제공한 국내 Shorts는 `영상 검토 후보`라는 중립 영역에서만 원문 확인용으로 표시됨

## 검증 명령

```bash
pnpm run qa:public
pnpm run qa:education-tf
pnpm run qa:video-db
QA_URL=https://kradavid.github.io/cellpinda_gaba_sum/ pnpm run qa:matrix
```

현재 목표는 기술적으로 상당 부분 구현됐지만, 위 인간·현장 게이트가 남아 있으므로 전체 목표는 계속 진행 중이다.
