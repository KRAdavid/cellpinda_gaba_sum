# 일반 GABA 교육 공개본 수용 매트릭스

이 문서는 제품 판매 사이트가 아닌 일반 GABA 교육 공개본의 완료 증거와 인간 승인 게이트를 구분한다. 기술 QA가 통과해도 사람 검토·실기기·현장 증거가 없으면 최종 완료로 표시하지 않는다.

## 현재 운영 게이트

- 인간 역할 배정: `0/7`
- 출처 사람 검토: `0/5`
- 등록 영상 공개 승인: `DB 승인 이력 2/11(해외 AUTH) · 국내 공개 승인 0/9`
- 첫 회의 입력: 필요
- 실제 iOS·Android: 미검증
- A/B/C 현장 세션: 미실시

## 검증 명령

```bash
pnpm run qa:public
pnpm run qa:education-tf
pnpm run qa:video-db
QA_URL=https://kradavid.github.io/cellpinda_gaba_sum/ pnpm run qa:matrix
```

현재 목표는 기술적으로 상당 부분 구현됐지만, 위 인간·현장 게이트가 남아 있으므로 전체 목표는 계속 진행 중이다.
