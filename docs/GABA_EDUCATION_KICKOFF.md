# 일반 GABA 교육 TF 첫 회의 준비서

## 회의 목적

GABA를 모르는 소비자가 GABA의 이름·일반 기능·연구 범위를 쉽고 빠르게 이해하도록 공개 교육 흐름과 영상 감리 기준을 결정한다. 제품·후기·판매 문구를 결정하는 회의가 아니다.

## 45분 안건

| 시간 | 안건 | 결정 산출물 |
| --- | --- | --- |
| 0~5분 | 일반 GABA 교육 범위·제품 제외 고정 | 포함·제외 기준 |
| 5~12분 | 9장 소비자 흐름·일상 용어 | 첫 도입 문장·오해 방지 문장 |
| 12~20분 | GABA 정의·신경 신호 조절 | SCIENCE/MEDICAL 검토 문장 |
| 20~28분 | 일반 GABA 연구와 한계 | 조건·결론·보류 문장 |
| 28~36분 | 권위 영상 DB와 Shorts 감리 | 영상별 판정·다음 담당 |
| 36~41분 | 일일 모니터·TF 운영 보드 | 매일 검토 순서·회의 액션 |
| 41~45분 | 역할·기한·다음 검토일 | 결정 대장 입력 |

## 반드시 결정할 질문

1. 일반 소비자가 기억할 GABA 핵심 문장은 무엇인가?
2. `억제성 신경전달물질`을 어떤 일상 용어로 설명할 것인가?
3. 뇌의 브레이크 비유가 진단·결핍·치료로 오해되지 않는가?
4. 일반 GABA 연구의 조건과 한계를 어디에 배치할 것인가?
5. 권위 영상은 원문 링크와 허용된 임베드 중 어떤 방식으로 사용할 것인가?
6. 후보 영상별 화자·발언·근거·권리 확인자는 누구인가?
7. 매일 새 후보를 어떤 순서로 감리하고 언제 `PUBLISH_GENERAL`로 바꿀 것인가?
8. 소비자 화면에서 외부 원문보다 다음 카드가 먼저 선택되는가?

## 첫 회의 산출물

- 공개 9장 흐름의 문장 승인·보류 목록
- 출처 사람 검토 결과
- 영상별 `무엇을 어떻게 소개했나`·인물 소개·감리 필드 검토
- 다음 일일 모니터 담당과 15분 검토 순서
- A/B/C 현장 세션 일정과 관찰자
- [`TF_DECISION_REGISTER.md`](TF_DECISION_REGISTER.md)와 [`TF_REVIEW_LOG.md`](TF_REVIEW_LOG.md)의 다음 액션
