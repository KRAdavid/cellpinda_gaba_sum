# 일반 GABA 교육 TF 첫 회의 준비서

## 회의 목적

제품을 소개하거나 판매 문구를 결정하는 회의가 아니다. GABA를 모르는 사람이 과학적 근거와 권위 있는 설명 영상을 통해 GABA의 기본 개념을 빠르게 이해하도록 만드는 편집 기준과 첫 제작 범위를 결정한다.

## 45분 회의 안건

| 시간 | 안건 | 결정 산출물 |
| --- | --- | --- |
| 0~5분 | 범위 고정: 일반 GABA 교육, 제품 정보 제외 | 포함·제외 범위 확정 |
| 5~12분 | 소비자 학습 목표와 일상 도입 문장 | 첫 2장 카드 문안 |
| 12~22분 | GABA 정의·기능 설명의 과학 출처 | 승인 출처 2~4개 |
| 22~30분 | 수면·스트레스 연구의 표현 범위 | 사용 문장·보류 문장 |
| 30~37분 | 권위 영상 후보와 사용 방식 | 임베드·링크·인용 방식·감리 판정 |
| 37~42분 | 6~8장 스토리보드와 영상 위치 | 1차 제작안·이탈 방지 동선 |
| 42~45분 | 담당자·기한·다음 검토일 | 결정 대장과 액션 목록 |

## 첫 회의에서 결정할 질문

1. 일반 소비자가 페이지를 본 뒤 반드시 기억해야 할 GABA 핵심 문장은 무엇인가?
2. `억제성 신경전달물질`을 어떤 일상 용어로 설명할 것인가?
3. `뇌의 브레이크`, `GABA 부족`, `수면 개선` 같은 표현을 어디까지 허용할 것인가?
4. 수면·스트레스 연구는 긍정 결과보다 조건과 한계를 어떻게 함께 보여줄 것인가?
5. 공유 영상은 전체 임베드할 것인가, 특정 구간 링크만 제공할 것인가?
6. 영상·이미지·자막을 재사용할 권리가 있는가?
7. 제품·후기·판매 정보가 현재 코드와 공개 페이지에서 완전히 제거되었는가?
8. 자동 수집된 후보를 누가 매일 원문·자막·권리·근거까지 감리하고 공개 승인할 것인가?

## 첫 제작 산출물

- 일반 GABA 교육 카드 6~8장
- 30~60초 영상 1개 또는 권위 영상 임베드 1개
- 영상 대본·자막·출처·발언 구간
- 일반 연구 출처 등록부
- 제품·후기·판매 내용 제외 확인표
- 모바일 공개본 QA 캡처와 변경 이력
- 매일 수집되는 숏츠 검토 대기함과 승인·보류·배제 로그
