# GABA 영상 콘텐츠 DB

일반 GABA 교육 페이지에서 활용할 수 있는 영상 후보의 조사·감리 DB다. 제품 판매 페이지, 구매 후기, 제품 효능 자료와 섞지 않는다.

## 현재 검토 기준

- 확인일: 2026-09-22
- 입력 범위: 사용자가 제공한 YouTube Shorts 8건
- YouTube 메타데이터: 사용자 제공 Shorts 8건을 oEmbed로 제목·채널 응답 확인했으며, 장편 후보 VID-01까지 포함한 현재 등록 YouTube 링크 9건은 일일 모니터에서 별도로 확인한다. 이 점검은 영상 내용·화자 권위·과학적 타당성·권리를 승인하지 않는다.
- 자막 접근 감사: [2026-09-22 자막 감사 기록](gaba-video-daily/GABA_VIDEO_CAPTION_AUDIT_2026-09-22.md)에서 등록 YouTube 링크별로 watch 페이지 자막 트랙과 본문 접근 상태를 분리 기록했으며, 자막 본문 자동 확보는 HTTP 429로 실패했다.
- 자막 상태: 제공된 링크의 원문 자막을 안정적으로 확보하지 못한 영상이 있어, 아래 예비 항목은 제목·공개 설명·채널 공개 프로필 기반이다.
- 공개 조건: 예비 요약은 게시 승인 근거가 아니다. 원문 시청과 자막·발언 구간 확인 전에는 HOLD 또는 LIMITED_USE 후보로 유지한다. 현재 LIMITED_USE 표시는 추가 확인 후 사용할 수 있는 후보라는 뜻이지 공개 승인이라는 뜻이 아니다.
- 소비자 영상 요약 미리보기: `SHARED_GABA_VIDEOS`가 오늘 공유된 국내 YouTube Shorts 7건(SHORT-02~08)을 한 편씩 YouTube 썸네일과 소비자용 중립 카피로 소개한다. 원본 제목·예비 요약·사업자 감리 문장은 발표자 DB에 보존하고, 소비자 화면에서는 수면제·영양제·보충제 등 상업·치료성 표현을 재전달하지 않는다. compact한 순서 인덱스와 이전·다음 이동으로 현재 영상만 집중해서 보고, 먼저 상세 감리 패널을 연 뒤 원문 링크를 선택한다. 영상 파일을 내려받거나 재편집·재게시하지 않으며, 실제 전체 영상은 YouTube 원문에서 확인한다. SHORT-01은 재게시·권리 확인 전이라 제외한다.
- 해외 영상 사용 중단: AUTH-01·AUTH-02는 감리 이력 보존을 위한 내부 DB에만 남기고 소비자 영상 요약 섹션에서 제외한다.
- 일반 연구 경계: [GABA 일반 생리 참고](https://pubmed.ncbi.nlm.nih.gov/31869147/)와 [경구 GABA의 스트레스·수면 체계적 문헌고찰](https://pubmed.ncbi.nlm.nih.gov/33041752/)을 별도 출처로 관리한다. 해당 연구는 특정 셀핀다 제품의 효능을 입증하는 자료가 아니다.

## 영상별 감리 필드

사이트의 영상 DB(`src/gabaVideos.ts`)는 아래 필드를 영상마다 함께 보관한다. 원본 `summary`·`personSummary`와 감리 필드는 발표자용 DB에서 확인하고, 소비자용 영상 섹션에는 별도 `public*` 카피를 사용해 일반 GABA 교육과 원본의 상업·치료성 주장을 분리한다.

| 필드 | 의미 |
| --- | --- |
| `publicTitle`·`publicSummary`·`publicPersonSummary`·`publicOperatorSentence` | 소비자 영상 섹션에 표시하는 중립 카피. 원본 제목·예비 주장·사업자 감리 문장을 그대로 재전달하지 않음 |
| `contentBasis` | 원문·대본 확인인지, 공식 강의 페이지인지, 제목·공개 설명만 본 예비 확인인지 |
| `previewImage`·`previewLabel` | 공식 원문이 제공하는 미리보기 이미지 또는 기관 미디어 블록 정보. 영상 파일을 복제하는 필드가 아님 |
| `operatorSentence` | 사업자가 고객 앞에서 읽을 수 있는 일반 교육용 한 문장 |
| 고객 설명 3문장 | 발표자 화면에서 복사할 수 있는 안전한 설명. `PUBLISH_GENERAL`이 아닌 후보는 영상 제목·예비 요약을 고객 문장에 그대로 넣지 않고 검토 후보·원문 확인 필요로 고정 |
| `authorityEvidenceUrl` | 화자·소속을 확인하는 독립 출처 링크. 자격 확인과 영상 주장·효능·공개 승인은 별도임 |
| `researchEvidenceUrl` | 해당 화자와 연결된 연구 기록 링크. 연구 공저·경력 확인과 영상 주장·제품 효능·공개 승인은 별도임 |
| `authorityLevel` | 공식 원출처로 확인됨, 부분 확인, 미확인 |
| `evidenceLevel` | 일반 설명 근거 A~D 또는 아직 미검토 |
| `claimCategories` | 일반 생리, 경구 GABA 인체 연구, 수면·스트레스, 질환·치료, 제품·상업성 중 확인된 주장 범위 |
| `rightsStatus` | 원문 링크 방식, 권리 확인 필요, 사용하지 않음 |
| `usageMode` | 원문 링크, 허용 시 임베드, 검토용, 공개 제외 |
| `nextAction` | 다음 감리 담당자가 실제로 확인할 한 가지 행동 |

발표자용 영상 DB의 `이 영상 감리 기록 초안`은 위 감리 기준을 회의 전에 채워 두는 작업 도구다. 영상 DB 상태줄의 `감리 초안 n건`은 현재 브라우저에 저장된 초안 수를 뜻하며 공개 승인 수가 아니다. 담당자·역할·결정 초안·확인 타임코드·5개 확인 체크·팀 메모를 영상 ID별로 브라우저 `localStorage`에만 저장하며, 공식 DB 상태·공개 승인·모니터 스냅샷을 변경하지 않는다. 개별 초안은 선택 영상에서, 여러 초안은 `작성 초안 전체 복사`에서 회의용 텍스트로 복사할 수 있다. 최종 판정은 원문·자막·근거·권리 확인 후 문서와 DB에 사람이 반영한다.

발표자 영상 DB의 `회의용 요약 복사`는 해당 날짜의 자동 감리 확인일, 채널·검색어 수, 신규·대기 후보, 링크·메타데이터·자막 경고, 오늘 우선 후보와 권위 후보 확인 큐를 한 번에 복사한다. 이 내용은 제목·공개 설명 기반의 업무 우선순위이며, 원문·자막·화자·근거·권리 확인 전에는 공개 승인이나 권위 승인으로 사용할 수 없다.

일일 감리에는 영상 원문 링크와 별도로 `권위·연구 출처 링크` 접근 상태가 포함된다. 출처 링크가 열리는지는 운영 점검일 뿐, 인물 자격·실제 화자 일치·연구 내용·과학적 타당성·권리·공개 승인을 의미하지 않는다.

이 필드들은 발표자의 직함만으로 공개를 승인하지 않도록 권위·근거·권리·사용방식을 분리한다. `TITLE_AND_PUBLIC_DESCRIPTION`인 영상은 원문을 직접 확인하기 전까지 공개 근거 영상으로 사용하지 않는다.
