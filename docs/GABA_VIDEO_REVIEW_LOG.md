## 2026-09-22 공개 후보·권위 영상 라벨 정합성

공개 소비자 섹션의 국내 Shorts 7건은 원문·자막·화자·권리의 사람 감리 전이므로 `영상 검토 후보`로만 표시한다. 발표자 모드의 `영상 DB 감리`와 `PUBLISH_GENERAL` 판정은 별도 승인 영역으로 유지하며, 개별 영상의 권위 수준은 `VERIFIED / PARTIAL / UNVERIFIED` 필드와 출처로 확인한다. 소비자 화면·README·운영 가이드·릴리스 인수인계의 표현을 같은 기준으로 맞추고, 마지막 카드의 안내도 `영상 검토 후보`로 변경했다. 공개 URL 320·390·1440px 상호작용 QA와 정적 문서 QA를 다시 통과했다. 결정은 **기술·카피 PASS / 사람 감리 HOLD**이며, 다음 회차에는 후보별 원문 타임코드·화자 자격·주장 근거·사용권을 확인한 뒤에만 `LIMITED_USE` 또는 `PUBLISH_GENERAL`로 판정한다.

이동환·손유리·신원철 후보의 화자·소속 확인 출처를 각각 직무스트레스연구소, 서울정형외과·신경과, 대한수면연구학회 공식 페이지로 보강했다. 신원철 후보의 관련 GABA 연구 기록은 `researchEvidenceUrl`로 별도 연결했다. 이는 인물·소속·연구 경력 확인을 돕는 보조 근거이며 영상 발언·자막·상업성·권리·제품 효능·공개 승인을 대신하지 않는다. 결정은 **인물 확인 출처 PASS / 영상 주장·공개 승인 HOLD**다.
