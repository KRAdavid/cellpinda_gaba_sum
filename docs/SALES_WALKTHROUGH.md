# 사업자용 GABA 설명 가이드

공개 페이지를 고객 상담·매장 설명·온라인 미팅에서 사용할 때의 기본 진행안이다. 화면의 카드 흐름을 유지하고, 연구·제품·후기를 서로 다른 정보로 설명한다.

## 2분 진행안

1. 공개 페이지를 열고 `발표 모드`를 누른다.
2. 01~05번 카드를 순서대로 넘기며 일상적인 휴식과 GABA 일반정보를 설명한다.
3. 06번 연구 카드에서 `일반 GABA 연구 내용 보기`를 눌러 연구 조건과 한계를 먼저 보여준다.
4. `다음 카드로 계속 보기`를 눌러 07번 제품 카드로 이동한다.
5. 제품 패널에서 공개 안내 범위인 `셀핀다 가바 1500 · 30포 구성 · 기타가공품`만 설명한다.
6. 고객이 구매·후기를 요청할 때만 패널 하단의 스마트스토어 보조 링크를 안내한다.
7. 상담 중 특정 카드만 다시 보내야 하면 `현재 카드 링크 복사`를 사용한다.

## 권장 설명 문장

- “이 화면은 셀핀다 제품 관련 소비자 안내 페이지이고, 광고성 정보가 포함되어 있습니다.”
- “앞의 연구는 일반 GABA 연구라서 셀핀다 제품의 효능을 직접 입증하는 자료는 아닙니다.”
- “제품 구성과 식품 유형은 화면의 공개 안내 범위로만 보시고, 섭취법과 주의사항은 최신 포장 표시를 확인해 주세요.”
- “후기는 구매자의 개인 경험이므로 연구자료나 모든 사람에게 같은 결과가 나타난다는 뜻은 아닙니다.”

## 답변을 보류해야 하는 질문

| 고객 질문 | 안전한 답변 방향 |
| --- | --- |
| “숙면에 도움이 되나요?” | 일반 GABA 연구와 제품 정보는 별개이며, 특정 효과를 보장한다고 말하지 않는다. 최신 표시사항과 개인 상황을 확인하도록 안내한다. |
| “불안·스트레스가 줄어드나요?” | 질환·증상 개선을 단정하지 않는다. 연구 조건과 한계를 먼저 보여주고 제품 효능으로 연결하지 않는다. |
| “하루에 몇 포 먹나요?” | 연구에서 사용한 양을 제품 섭취량으로 바꾸지 않는다. 최신 포장 표시사항을 확인한다. |
| “약이나 다른 영양제와 같이 먹어도 되나요?” | ‘상호작용 없음’이라고 단정하지 않는다. 제품 표시사항과 복용 중인 약을 기준으로 의료전문가에게 확인하도록 안내한다. |
| “후기를 광고에 써도 되나요?” | 원문 재게시 권한, 작성일·대상 제품, 편집 여부, 경제적 이해관계를 확인하기 전에는 재게시하지 않는다. |

## 영업 현장에서 피할 표현

`숙면 보장`, `불면 개선`, `스트레스 완화`, `집중력 향상`, `뇌 피로 회복`, `부작용 없음`, `상호작용 없음`, `누구에게나 효과`, `약 대신`과 같은 표현은 제품 분류·최신 표시사항·별도 근거 승인 전에는 사용하지 않는다.

## 상담 종료 기준

상담의 목표는 구매를 압박하는 것이 아니라 다음 행동을 명확하게 하는 것이다.

- 연구를 더 보고 싶음 → 연구 패널의 원문 링크
- 제품 구성을 확인하고 싶음 → 제품 패널의 스마트스토어 링크
- 다른 구매자 경험을 보고 싶음 → 후기 패널의 스마트스토어 후기 링크
- 섭취법·주의사항을 묻는 중임 → 최신 포장 표시사항 확인 후 답변

제품 최신 표시사항, 후기 사용권, 경제적 이해관계가 확인되기 전에는 이 가이드를 최종 광고 문안 승인서로 사용하지 않는다.
