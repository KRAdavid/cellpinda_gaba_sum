# 일반 GABA 교육 사업자 운영 가이드

이 문서는 제품 판매 자료가 아니라, GABA를 처음 듣는 사람에게 일반 GABA 교육 페이지를 설명할 때 사용하는 현재 기준 가이드다.

## 시작 링크

- 소비자: `https://kradavid.github.io/cellpinda_gaba_sum/`
- 발표자: `https://kradavid.github.io/cellpinda_gaba_sum/?mode=presenter&card=1#story`

## 8장 설명 흐름

`01 일상에서 생기는 변화 → 02 여유가 생기는 날 → 03 머리가 계속 바쁜 날 → 04 뇌가 쉬는 시간 → 05 GABA란 무엇일까 → 06 GABA가 하는 일 → 07 일반 GABA 연구는 어디까지 알까 → 08 한 문장으로 정리하면`

한 화면에는 한 메시지만 둔다. 소비자는 하단의 다음 메시지 안내를 따라가며 같은 읽기 위치에서 다음 장면을 연다. 08번 이후 별도 영상 요약 섹션에서 오늘 공유된 검토 후보의 히어로 샷·예비 요약·인물 소개를 확인한다. `PUBLISH_GENERAL` 승인 전에는 권위 영상처럼 소개하지 않으며, 원문 링크는 요약과 상세 감리를 확인한 뒤 선택한다.

공개 화면에는 소비자용 안전 요약만 먼저 싣고, 원자료 제목·감리 후보·일일 모니터 원자료는 발표자 모드에서만 불러온다. 따라서 공개 페이지를 열었을 때 사업자용 후보 정보가 소비자 흐름에 섞이지 않는지 `pnpm run qa:bundle`로 확인한다.

## 설명 원칙

1. “GABA가 부족해서 그렇다”라고 진단하지 않는다.
2. GABA의 일반 생리 기능과 경구 GABA 인체 연구를 구분한다.
3. `일반 GABA 연구`라는 범위를 항상 말한다.
4. 연구·영상이 특정 제품의 효능이나 개인의 결과를 보증한다고 말하지 않는다.
5. 수면제 대체, 불안·불면 해결, 부작용 없음, 누구에게나 안전 같은 표현은 사용하지 않는다.
6. 제품·가격·구성·섭취량·후기·판매 링크는 이 공개 교육 흐름에서 다루지 않는다.

## 영상 DB 사용법

발표 모드의 `영상 DB`에서 다음 순서로 확인한다.

1. 운영 보드의 `오늘 바로 할 일`에서 15분 시작 순서를 확인하고, 첫 번째 `감리 시작` 버튼으로 우선 영상을 연다. 이 순서는 자동 정렬에서 사람 감리로 넘어가기 위한 진입점이다.
2. 상단 `오늘 먼저 감리할 등록 영상`의 3건을 먼저 확인한다. 이 목록은 상태와 미완료 기록을 기준으로 자동 정렬하며, 권위·과학적 타당성·권리를 승인하는 목록이 아니다.
3. `검토 필요` 또는 제목·채널·화자 검색으로 후보를 찾는다.
4. 선택 영상의 `무엇을 어떻게 소개했나`와 `인물 소개`를 읽는다.
5. 요약 근거·권위·근거·주장 범위·권리·사용 방식을 확인한다.
6. 영상별 5개 확인 항목(원문·자막·화자·권리·주장 범위)을 기록하고 `다음 감리 행동`을 담당자에게 넘긴다.
7. 승인 영상만 고객에게 일반 교육 보조 자료로 소개한다.

사업자 설명 한 문장은 일반 교육 범위에 한정되며, 발표 모드에서 복사할 수 있다. `PENDING_REVIEW`, `HOLD`, `LIMITED_USE`, `EXCLUDE` 영상은 공개 승인 영상처럼 소개하지 않는다.

선택한 영상 상세의 `이 영상 감리 링크 복사`는 팀 내부 검토용이다. 링크를 받은 사람은 발표자 모드와 해당 영상의 상세 감리 패널로 바로 들어갈 수 있다. 이 링크는 고객용 링크가 아니며, 링크를 열었다고 해서 권위·과학적 타당성·공개 승인이 완료되는 것은 아니다.

공개 영상 요약의 `이 영상 링크 공유`는 발표자 모드 없이 해당 영상부터 시작하는 고객용 링크를 만든다. 링크를 받은 사람은 영상 요약 섹션의 같은 후보에서 시작하며, 영상이 `PUBLISH_GENERAL`로 승인되었다는 뜻은 아니다.

`운영 보드`의 `오늘의 토론 논점`에서는 논점별 회의 결정·다음 담당·기한·근거·이견을 브라우저 로컬 초안으로 기록한다. `회의 논점·기록 복사`와 `감리 패킷 JSON 저장`으로 팀에 전달할 수 있지만, 이 기록은 공식 역할 배정·영상 상태·공개 승인을 바꾸지 않는다.

같은 보드의 `A/B/C 현장 검증 기록`은 실제 세션의 설명자·관찰자·기기·명확도·첫 행동 시간·외부 선행 이탈·오해·다음 액션을 기록한다. 고객 개인정보·건강 상태·복용 약은 기록하지 않으며, 입력은 현장 PASS나 최종 승인으로 간주하지 않는다.

## 일일 모니터 사용법

발표 모드 영상 DB의 `일일 감리 상태`에서 마지막 확인일·채널·검색어 성공 수·검토 대기·우선 감리·신규 후보·자동 공개 수를 확인한다. 등록 영상 원문 링크, YouTube 제목·채널 메타데이터, watch 페이지 자막 트랙 접근 확인 수·경고 수도 별도 지표로 보되, 세 상태 모두 권위·내용·권리 승인과 연결하지 않는다. 자동 수집은 후보 발견과 우선순위 분류만 하며, 매일 공개 승인을 대신하지 않는다.

현재 종료 순서는 `VIDEO 원문·자막·화자 → SCIENCE/MEDICAL 주장·근거 → RIGHTS 사용 방식 → PM/UX 공개 문장`이다.
