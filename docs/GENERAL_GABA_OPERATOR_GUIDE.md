# 일반 GABA 교육 사업자 운영 가이드

이 문서는 제품 판매 자료가 아니라, GABA를 처음 듣는 사람에게 일반 GABA 교육 페이지를 설명할 때 사용하는 현재 기준 가이드다.

## 시작 링크

- 소비자: `https://kradavid.github.io/cellpinda_gaba_sum/`
- 발표자: `https://kradavid.github.io/cellpinda_gaba_sum/?mode=presenter&card=1#story`

## 9장 설명 흐름

`01 일상 속 쉽게 흥분한 날 → 02 충분히 쉰 날 → 03 뇌 과부하 → 04 회복의 시간 → 05 GABA 이름 → 06 신경 신호 조절 → 07 일반 GABA 연구 → 08 권위 설명 영상 → 09 한 문장 정리`

한 화면에는 한 메시지만 둔다. 발표자는 다음 카드로 이어가고, 연구·영상 원문은 현재 패널에서 맥락과 한계를 먼저 설명한 뒤 필요한 경우에만 외부 링크를 연다.

## 설명 원칙

1. “GABA가 부족해서 그렇다”라고 진단하지 않는다.
2. GABA의 일반 생리 기능과 경구 GABA 인체 연구를 구분한다.
3. `일반 GABA 연구`라는 범위를 항상 말한다.
4. 연구·영상이 특정 제품의 효능이나 개인의 결과를 보증한다고 말하지 않는다.
5. 수면제 대체, 불안·불면 해결, 부작용 없음, 누구에게나 안전 같은 표현은 사용하지 않는다.
6. 제품·가격·구성·섭취량·후기·판매 링크는 이 공개 교육 흐름에서 다루지 않는다.

## 영상 DB 사용법

발표 모드의 `영상 DB`에서 다음 순서로 확인한다.

1. `검토 필요` 또는 제목·채널·화자 검색으로 후보를 찾는다.
2. 선택 영상의 `무엇을 어떻게 소개했나`와 `인물 소개`를 읽는다.
3. 확인 기반·권위·근거·주장 범위·권리·사용 방식을 확인한다.
4. `다음 감리 행동`을 담당자에게 넘긴다.
5. 승인 영상만 고객에게 일반 교육 보조 자료로 소개한다.

사업자 설명 한 문장은 일반 교육 범위에 한정되며, 발표 모드에서 복사할 수 있다. `PENDING_REVIEW`, `HOLD`, `LIMITED_USE`, `EXCLUDE` 영상은 공개 승인 영상처럼 소개하지 않는다.

## 일일 모니터 사용법

발표 모드 영상 DB의 `일일 감리 상태`에서 마지막 확인일·채널·검색어 성공 수·검토 대기·우선 감리·신규 후보·자동 공개 수를 확인한다. 등록 영상 원문 링크, YouTube 제목·채널 메타데이터, watch 페이지 자막 트랙 접근 확인 수·경고 수도 별도 지표로 보되, 세 상태 모두 권위·내용·권리 승인과 연결하지 않는다. 자동 수집은 후보 발견과 우선순위 분류만 하며, 매일 공개 승인을 대신하지 않는다.

현재 종료 순서는 `VIDEO 원문·자막·화자 → SCIENCE/MEDICAL 주장·근거 → RIGHTS 사용 방식 → PM/UX 공개 문장`이다.
