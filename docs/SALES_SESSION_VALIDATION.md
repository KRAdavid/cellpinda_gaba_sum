# 사업자 영업 현장 검증 양식

공개 페이지의 기술 QA와 실제 사업자 사용성은 별도로 검증한다. 이 양식은 최소 3회의 실제 상담·매장 설명·온라인 미팅에서 같은 흐름을 관찰하고, 고객 개인정보나 건강정보를 기록하지 않기 위한 양식이다.

## 세션 KPI 정의

이 KPI는 제품 효능이나 고객의 건강 변화를 측정하지 않는다. 페이지가 영업 설명을 끊지 않고 다음 행동을 안내하는지 판단하기 위한 운영 지표다. 세션이 3회뿐인 파일럿에서는 시장 성과로 일반화하지 않고, 문구·카드 순서·공유 동작을 고칠 근거로만 사용한다.

| 구분 | 지표·계산 | 파일럿 통과 기준 | 담당 |
| --- | --- | --- | --- |
| 주 KPI | 무이탈 흐름 완주율 = 외부 페이지를 먼저 열지 않고 의도한 다음 카드·행동까지 도달한 세션 수 ÷ 전체 세션 수 | A/B/C 각 1회 모두 통과(3/3) | 사업·영업 / UX·QA |
| 주 KPI | 다음 행동 명확도 = 고객이 설명 없이 연구·제품·후기·다음 카드 중 다음 행동을 고른 정도(1~5 관찰 점수) | 세션별 4점 이상, `무엇을 봐야 할지 모르겠다` 1회 이하 | 사업·영업 / 관찰자 |
| 주 KPI | 고객용 링크 전달 성공 = 공유된 URL이 의도한 카드에서 열리고 `mode=presenter`가 없는 세션 수 ÷ 링크 공유 세션 수 | 링크 공유 세션 100% | QA / 사업·영업 |
| 진단 KPI | 첫 다음 행동까지 시간 = 첫 카드 표시부터 고객이 첫 다음 카드·패널·공유 행동을 선택할 때까지의 초 단위 관찰값 | 고정 목표를 정하지 않고 A/B/C 간 병목 비교 | UX·QA |
| 가드레일 | P0 오류·미승인 효능/섭취량/안전성/상호작용 확정·개인정보/건강정보 기록 | 모두 0건 | 근거·준법 |

측정 시각은 분 단위 또는 초 단위만 기록하고 고객 이름·연락처·건강 상태·복용 약은 기록하지 않는다. `부분 통과`는 주 KPI를 통과로 계산하지 않으며, 재현 카드와 다음 액션을 함께 남긴다.

## 실제 세션 시나리오

3회는 같은 화면을 반복해서 보여주는 대신, 아래 세 가지 진입 상황을 각각 한 번씩 검증한다. 시나리오 기록에는 고객 이름·연락처·건강정보를 적지 않고, 이해를 막은 화면·질문·다음 액션만 적는다.

| 시나리오 | 시작점 | 진행 요청 | 통과 기준 |
| --- | --- | --- | --- |
| A. 전체 이야기 | 일반 URL 또는 `?mode=presenter&card=1#story` | 일상 장면 → 5분 휴식 → GABA 일반정보 → 일반 연구 → 제품 → 활용 TIP → 생활 루틴 → 후기 순서로 설명 | 고객이 연구와 제품 정보를 같은 근거로 이해하지 않고, 외부 페이지로 나가지 않은 채 11번까지 도달 |
| B. 제품 정보 우선 | 첫 화면 `제품 정보가 먼저라면` 또는 `?mode=presenter&card=7#story` | 제품 패널의 제한 공개 상태·표시사항 확인 순서 설명 후 카드 링크를 고객용으로 공유 | 발표자용 모드가 공유 링크에 남지 않고, 제품 사실을 최종 승인 정보로 오해하지 않음 |
| C. 근거 질문 대응 | `?card=6#story` | “수면·스트레스에 도움이 되나요?”, “다른 제품과 같이 먹어도 되나요?” 질문에 연구 한계·보류 문구로 답한 뒤 제품 카드로 이동 | 효능·상호작용·섭취량을 확정하지 않고, `다음 카드로 계속 보기`로 흐름을 유지 |

### 관찰자 기록 규칙

- 설명자는 고객에게 질문을 유도하되, 건강 상태나 복용 정보를 기록하지 않는다.
- 관찰자는 카드 번호, 사용한 표현, 페이지 이탈 여부, 다음 행동 혼선만 기록한다.
- 실패가 발생하면 문구를 임의로 고치지 말고 `TF_REVIEW_LOG.md`에 문제와 재현 단계를 먼저 남긴다.
- 카드 공유 후 고객 화면이 일반 모드인지 확인하고, 발표자 메모가 전달되지 않았는지 기록한다.

## 승인 기준

- 3회 모두 페이지 이탈 없이 연구 → 제품 → 후기 흐름을 설명할 수 있다.
- 3회 모두 제품 효능·섭취량·안전성에 대한 미승인 답변이 나오지 않는다.
- “다음 행동이 무엇인지 모르겠다”는 피드백이 1회 이하이고, 발생 시 화면 또는 진행안을 수정한다.
- P0 오류(외부 이탈, 잘못된 효능 연결, 제품 사실 오표시)가 0건이다.
- 세션 결과를 TF 리뷰 로그에 `문제 → 결정 → 변경 파일 → 검증 결과`로 반영한다.
