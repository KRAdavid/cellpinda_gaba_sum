# 사업자 영업 현장 검증 양식

공개 페이지의 기술 QA와 실제 사업자 사용성은 별도로 검증한다. 이 양식은 최소 3회의 실제 상담·매장 설명·온라인 미팅에서 같은 흐름을 관찰하고, 고객 개인정보나 건강정보를 기록하지 않기 위한 양식이다.

각 항목을 `통과 / 부분 통과 / 실패`로 기록하고, 실패가 있으면 재현 상황을 한 줄로 남긴다.

## 질문 대응 체크

다음 질문이 나왔을 때 영업 담당자가 보류 문구를 사용했는지 확인한다.

| 질문 유형 | 보류 기준 | 결과 |
| --- | --- | --- |
| 수면·스트레스·집중 효과 | 특정 효과를 보장하지 않고 일반 연구와 제품 정보를 분리 |  |
| 하루 섭취량·혼합 방법 | 최신 포장 표시사항 확인 전에는 답을 확정하지 않음 |  |
| 약·영양제와 병용 | 상호작용 없음을 단정하지 않고 전문가 확인 안내 |  |
| 후기 재사용 | 권리·작성 맥락·경제적 이해관계 확인 전 재게시하지 않음 |  |

## 승인 기준

- 3회 모두 페이지 이탈 없이 연구 → 제품 → 후기 흐름을 설명할 수 있다.
- 3회 모두 제품 효능·섭취량·안전성에 대한 미승인 답변이 나오지 않는다.
- “다음 행동이 무엇인지 모르겠다”는 피드백이 1회 이하이고, 발생 시 화면 또는 진행안을 수정한다.
- P0 오류(외부 이탈, 잘못된 효능 연결, 제품 사실 오표시)가 0건이다.
- 세션 결과를 TF 리뷰 로그에 `문제 → 결정 → 변경 파일 → 검증 결과`로 반영한다.
