## 실제 세션 시나리오

3회는 같은 화면을 반복해서 보여주는 대신, 아래 세 가지 진입 상황을 각각 한 번씩 검증한다. 시나리오 기록에는 고객 이름·연락처·건강정보를 적지 않고, 이해를 막은 화면·질문·다음 액션만 적는다.

| 시나리오 | 시작점 | 진행 요청 | 통과 기준 |
| --- | --- | --- | --- |
| A. 전체 이야기 | 일반 URL 또는 `?mode=presenter&card=1#story` | 일상 장면 → 5분 휴식 → GABA 일반정보 → 일반 연구 → 제품 → 후기 순서로 설명 | 고객이 연구와 제품 정보를 같은 근거로 이해하지 않고, 외부 페이지로 나가지 않은 채 07번까지 도달 |
| B. 제품 문의 우선 | 첫 화면 `제품 문의부터 보기` 또는 `?mode=presenter&card=7#story` | 제품 패널의 제한 공개 상태·표시사항 확인 순서 설명 후 카드 링크를 고객용으로 공유 | 발표자용 모드가 공유 링크에 남지 않고, 제품 사실을 최종 승인 정보로 오해하지 않음 |
| C. 근거 질문 대응 | `?card=6#story` | “수면·스트레스에 도움이 되나요?”, “다른 제품과 같이 먹어도 되나요?” 질문에 연구 한계·보류 문구로 답한 뒤 제품 카드로 이동 | 효능·상호작용·섭취량을 확정하지 않고, `다음 카드로 계속 보기`로 흐름을 유지 |

### 관찰자 기록 규칙

- 설명자는 고객에게 질문을 유도하되, 건강 상태나 복용 정보를 기록하지 않는다.
- 관찰자는 카드 번호, 사용한 표현, 페이지 이탈 여부, 다음 행동 혼선만 기록한다.
- 실패가 발생하면 문구를 임의로 고치지 말고 `TF_REVIEW_LOG.md`에 문제와 재현 단계를 먼저 남긴다.
- 카드 공유 후 고객 화면이 일반 모드인지 확인하고, 발표자 메모가 전달되지 않았는지 기록한다.

## 승인 기준

- 3회 모두 페이지 이탈 없이 연구 → 제품 → 후기 흐름을 설명할 수 있다.
- 3회 모두 제품 효능·섭취량·안전성에 대한 미승인 답변이 나오지 않는다.
- “다음 행동이 무엇인지 모르겠다”는 피드백이 1회 이하이고, 발생 시 화면 또는 진행안을 수정한다.
- P0 오류(외부 이탈, 잘못된 효능 연결, 제품 사실 오표시)가 0건이다.
- 세션 결과를 TF 리뷰 로그에 `문제 → 결정 → 변경 파일 → 검증 결과`로 반영한다.
