# 일반 GABA 교육 TF 구성·업무 배정표

이 TF는 제품 판매나 제품 효능을 검토하는 조직이 아니라, 일반 소비자를 위한 GABA 교육 자료를 만드는 편집·과학·영상·UX 협업팀이다.

실제 구성원 초대와 첫 업무 배정은 [`GABA_EDUCATION_TEAM_INVITE.md`](GABA_EDUCATION_TEAM_INVITE.md)를 사용한다. 이 문서는 역할을 임의로 채우지 않고, 사람 입력 전 상태를 `배정 필요`로 유지한다.

## AI-OPS에 위임한 업무

- 일반 GABA 교육 범위에 맞춰 기존 제품·후기·판매 흐름을 분리하거나 제거할 개편안 작성
- 과학 논문·공공기관 자료를 출처 등록부에 정리
- 권위 영상 후보의 제목·출처·발언 시점·주장·한계·권리 상태 기록
- 1페이지 1메시지 스토리보드와 영상 삽입 위치 제안
- 모바일 인페이지 영상 패널, 자막·대본·출처 링크 구현
- 문서·코드·브라우저·반응형 QA 및 변경 이력 보고
- 근거가 부족한 문장은 `HOLD`로 표시하고 과학·의학 검토자에게 전달

AI-OPS는 과학·의학적 최종 승인자나 영상 저작권 보유자가 아니다.

## 핵심 결정 참석자

첫 결정 회의에는 `PM`, `SCIENCE`, `MEDICAL`, `VIDEO`, `RIGHTS`, `UX`, `QA`가 참석한다. `VISUAL`은 시각화 안건에 참석한다. 핵심 역할의 실제 담당자와 백업이 입력되지 않으면 회의는 결정 회의가 아니라 준비 회의로 기록한다.

## 공개 전 필수 게이트

1. GABA 일반 정의와 기능 설명의 1차·권위 출처 등록
2. 수면·스트레스 연구의 대상·조건·결론·한계 등록
3. 영상별 원출처·발언 구간·자막·임베드 또는 인용 조건 확인
4. 제품·후기·판매 링크가 공개 페이지에 남아 있지 않은지 확인
5. 의학적 오해를 만들 수 있는 결핍·치료·효능 보장 표현 제거
6. 모바일 영상 재생·자막·대본·출처 링크 QA 통과
