# 후기 사용권·맥락 등록표

> **범위 밖 보관 문서:** 현재 공개 일반 GABA 교육본에는 후기 정보가 포함되지 않는다. 이 문서는 별도 제품 프로젝트에서만 사용한다.

구매자 후기를 공개 페이지나 영업 자료에서 사용하려면 후기별로 권리·작성 맥락·편집 여부·경제적 이해관계를 확인한다. 이 등록표가 채워지기 전에는 현재처럼 개인 경험 안내만 제공하고 원문·이미지를 재게시하지 않는다.

## 승인 규칙

- 출처에 게시되어 있다는 사실만으로 광고 재사용 권한이 생기지 않는다.
- 원문·이미지 사용권과 사용 범위, 편집 여부를 후기별로 확인한다.
- 제공·할인·협찬·고용 등 경제적 이해관계가 있으면 표시·검토 범위를 별도로 기록한다.
- 개인 경험을 객관적 연구 결과나 모든 사람에게 같은 결과가 나타나는 근거로 바꾸어 쓰지 않는다.
- 권리나 맥락이 불명확하면 `HOLD`로 남기고 외부 원문 링크도 고객이 직접 선택하는 보조 경로로만 둔다.
