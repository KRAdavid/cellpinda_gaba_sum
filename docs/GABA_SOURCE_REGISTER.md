## 공개 문장 초안

아래 문장은 공개 교육 화면에서 사용할 수 있도록 연구 결과를 긍정적으로 요약한 **AI_PRECHECKED 초안**이다. 과학·의학 담당자가 원문과 대조하기 전에는 `HUMAN_REVIEWED` 또는 최종 승인 문장으로 보지 않는다.

소비자 첫 화면에서는 실제 연구에서 관찰·보고된 긍정적 변화를 먼저 설명한다. 연구 대상·섭취량·기간·비교 조건은 같은 패널에서 함께 제공하되, 일반 GABA 연구 결과를 특정 제품의 효능으로 바꾸지 않는다.

## 사용 규칙

- 리뷰 논문은 원문과 연구 대상·조건·결론을 함께 확인한다.
- 일반 GABA 연구를 특정 제품 또는 특정 섭취량의 효능으로 바꾸지 않는다.
- `SCI 논문`이라는 표현만으로 연구의 질·제품 적용성·안전성을 보장하지 않는다.
- 공개 장면과 별도 영상 섹션에는 짧은 출처·검토 상태를, 자세한 패널에는 원문 링크와 한계를 표시한다.
- 발표자 화면의 `과학 출처 사람 검토 초안`은 검토자·담당 역할·결정 초안·원문 범위·한계·공개 문장 확인과 메모를 브라우저 로컬에 기록하고 감리 패킷으로 전달하기 위한 보조 입력이다. 이 입력은 등록부 상태를 `HUMAN_REVIEWED`로 바꾸거나 공개 승인을 만들지 않는다.

## 상태 정의

- `OPEN`: AI 사전 확인 전.
- `AI_PRECHECKED`: AI-OPS가 공개 초록·기관 자료와 범위·한계를 대조했지만 사람 과학·의료 검토 전.
- `HUMAN_REVIEWED`: 지정된 과학·의료 담당자가 원문·문장 범위·공개 사용 여부를 확인한 상태.
