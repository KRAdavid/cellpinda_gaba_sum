# 일반 GABA 교육 TF 토론 보드

공개 일반 GABA 교육 페이지를 계속 개선하기 위한 논점 대기열이다. 기술 QA, 사람 검토, 현장 검증을 구분하고 모든 결정은 `문제 → 관점 → 증거 → 결정 → 종료 조건`으로 남긴다.

## 상태 정의

| 상태 | 의미 |
| --- | --- |
| `OPEN` | 논점과 필요한 증거를 정리 중 |
| `READY FOR FIELD` | 화면·관찰 기준이 정해져 현장 확인 대기 |
| `IN TEST` | 사람 검토·기기·세션을 실행 중 |
| `DECIDED` | 적용·관찰·HOLD 중 하나를 결정 |
| `VERIFIED` | 정해진 종료 증거까지 확인 |

## 기술 사전 검토 결과

- 소비자 모드: 편집형 세로 장면 읽기·한 장면 한 메시지·모바일 장면 목차·하단 다음 메시지 행동 — 기술·시각 PASS, 현장 HOLD
- 연구·영상: 인페이지 패널·외부 원문 보조 경로 — 기술 PASS, 사람 근거·권리 HOLD
- 일일 모니터: 자동 수집·중복 제거·우선순위·날짜별 리포트 — 기술 PASS, 사람 감리 HOLD
- 사업자 모드: 영상 DB 필터·검색·감리 필드·설명 문장 복사 — 기술 PASS, 실제 세션 HOLD
