# GABA 영상 콘텐츠 감리 규칙

이 문서는 일반 GABA 교육 페이지에 사용할 의사·과학자·의료 전문가 영상과 숏츠를 같은 기준으로 검토하기 위한 운영 규칙이다. 영상의 유명세나 발표자의 직함만으로 게시를 승인하지 않는다.

## 1. 영상 한 건에 반드시 기록할 항목

| 구분 | 기록 내용 |
| --- | --- |
| 식별 | DB ID, URL, YouTube video ID, 채널명, 제목, 확인일, 공개일·길이(확인 가능할 때) |
| 내용 | 무엇을 소개했는지, 어떤 순서·비유·사례·시각자료로 소개했는지 |
| 인물 | 성명, 직업·전공, 소속·경력, 이를 확인한 원출처, 확인 수준 |
| 주장 | GABA 일반 생리, 경구 GABA 인체 연구, 수면·스트레스, 질환 치료, 제품 효능, 안전성·상호작용으로 분류 |
| 근거 | 영상 안의 논문·기관·수치 인용, 원문 확인 여부, 근거의 조건과 한계 |
| 이해관계 | 제품·병원·강의·책·제휴·구매 링크, 재게시 채널 여부 |
| 사용 조건 | 임베드, 원문 링크, 특정 구간 링크, 짧은 인용 중 가능한 방식과 저작권 확인 상태 |
| 판정 | 게시 가능, 제한 사용, 보류, 배제와 다음 조치 |

## 2. 출연자 권위 판정

권위는 영상 내용의 진실성을 대신하지 않는다. 다음을 별도로 기록한다.

- 확인: 공식 기관·학회·대학·병원 또는 원출처에서 성명과 자격·소속을 확인했다.
- 부분 확인: 공개 프로필이나 2차 자료에서 직업·경력 일부를 확인했지만 해당 영상의 실제 화자까지 확정하지 못했다.
- 미확인: 채널명·제목·자기소개만 있고 독립적인 원출처가 없다.
- 재게시 채널은 원래 출연자의 자격과 재게시자의 자격을 분리한다.
- 의사·과학자라는 자격이 있어도 특정 보충제의 효과·안전성·병용 가능성을 자동 승인하지 않는다.

## 3. 주장 감리 규칙

### 게시 가능한 일반 교육의 범위

- GABA가 무엇인지, 신경 신호를 조절하는 일반 생리학적 역할을 설명하는 내용
- 연구가 어떤 대상·조건·기간·용량을 살폈는지와 한계를 설명하는 내용
- 일반 GABA 연구를 소개하며 셀핀다 제품의 효능을 입증하지 않는다는 경계를 지키는 내용

### 반드시 보류하거나 삭제할 표현

- GABA가 부족해서 당신이 화를 낸다, 뇌가 망가졌다는 식으로 진단·결핍을 가정하는 표현
- 수면제 대신, 부작용이 없다, 누구에게나 안전하다, 불안·불면증을 해결한다처럼 치료·안전성을 단정하는 표현
- 식품에 GABA가 들어 있다는 사실만으로 경구 섭취 후 뇌·수면·스트레스 효과를 단정하는 표현
- 일반 GABA 연구를 특정 셀핀다 제품·제형·함량·섭취량의 효능으로 연결하는 표현
- 후기·판매 페이지·협찬 설명을 연구 결과처럼 보여주는 편집

## 4. 근거 수준과 최종 판정

근거 수준과 출연자 권위는 별도 등급으로 남긴다.

| 등급 | 의미 | 사이트 사용 |
| --- | --- | --- |
| A | 원문 논문·공공기관 자료가 확인되고 영상 발언과 일치 | 일반 교육 문장에 제한 사용 가능 |
| B | 발표자의 전문성은 확인되며 일반 설명은 타당하지만 영상 내 근거·범위가 불완전 | 일반 정의·연구 소개만 제한 사용 |
| C | 인플루언서·재게시·출처 없는 설명이 중심 | 공개 근거 영상으로 사용하지 않음 |
| D | 제품 판매·질환 치료·안전성 단정 또는 근거와 불일치 | 배제 |

| 판정 | 의미 |
| --- | --- |
| PUBLISH_GENERAL | 일반 GABA 설명 구간만 공개 페이지에 임베드·원문 링크로 사용 가능 |
| LIMITED_USE | 자격과 구간을 추가 확인한 뒤 일반 정의·연구 한계만 사용 |
| HOLD | 자막·출연자·근거·권리 중 하나 이상이 확인되지 않음 |
| EXCLUDE | 과장·질환 치료·제품 효능 연결·권리 문제 등으로 사용하지 않음 |
| PENDING_REVIEW | 일일 모니터가 새로 발견했지만 사람의 감리 전인 상태 |
| AUTO_FILTERED | 제목 키워드가 없어 설명란 키워드 오탐으로 자동 수집 대상에서 제외한 상태 |

### 사용자 제공 영상의 링크 전용 검토 노출

사용자가 직접 공유한 YouTube Shorts는 `SHARED_GABA_VIDEOS`에 별도로 모아 원문 링크·썸네일·예비 요약만 보여줄 수 있다. 이 영역은 `PUBLISH_GENERAL` 승인과 다르며, 영상의 내용을 과학적 근거로 인용하거나 제품 효능으로 연결하지 않는다. 현재 영상과 상세 패널에는 `오늘 공유 · 원문 확인 필요`를 표시하고, 다음 조건을 지킨다.

- `EXCLUDE` 영상은 링크 전용 영역에도 넣지 않는다.
- 제목·공개 설명 기반 요약은 `예비`로 표시하고 자막·전체 발언으로 확정하지 않는다.
- 영상 파일을 내려받거나 재편집·재게시하지 않고 YouTube 원문으로 연결한다.
- `무엇을 어떻게 소개했나`, `인물 소개`, 근거·권리·주장 범위·다음 감리 행동을 영상별로 기록한다.

## 5. 한 영상 요약 문장 형식

최종 DB에는 아래 두 문장을 반드시 분리한다.

1. 무엇을 어떻게 소개했나: 제목·설명 기반인지, 자막·전체 시청 기반인지 명시하고 핵심 메시지와 전달 방식만 요약한다.
2. 인물 소개: 확인된 자격·소속만 쓰고 확인되지 않은 경력은 확인 필요로 남긴다.

그 다음에 근거 감리, 상업적 이해관계, 사이트 사용 판정, 다음 확인 작업을 붙인다. 도움이 된다는 결론은 영상에 등장했다는 이유만으로 DB에 기록하지 않고, 어떤 연구·조건을 가리키는지 확인된 경우에만 제한적으로 기록한다.

## 6. 일일 운영 규칙

1. 매일 새 영상의 제목·채널·공개일·영상 ID를 수집한다.
2. 기본 자동 수집은 제목에 가바·GABA가 직접 들어간 후보만 넣는다. 설명란에만 등장한 영상은 오탐 가능성을 검토한다.
3. 새 후보는 자동으로 `PUBLISH_GENERAL` 승인하지 않는다. 사용자가 공유한 링크를 별도 검토 섹션에 보일 때도 `EXCLUDE`는 제외하고, 예비 요약·원문 확인 필요 라벨·감리 필드를 함께 표시한다.
4. VIDEO 담당은 원문 시청·자막·출연자 확인을 하고 SCIENCE/MEDICAL은 주장과 근거를 감리한다.
5. RIGHTS는 임베드·원문 링크·인용 가능 범위를 확인한다.
6. 승인된 영상만 상세 DB에서 PUBLISH_GENERAL 또는 LIMITED_USE로 바꾼다.
7. 공개 사이트에는 일반 GABA 설명 영상 라벨과 영상의 의견·일반 연구를 셀핀다 제품 효능으로 해석하지 말라는 경계를 함께 둔다.
8. 매일 변경된 후보 수, 승인·보류·배제 수, 다음 조치를 회의 로그에 남긴다.

## 7. 자동화의 한계

자동화는 후보 수집과 중복 확인까지만 담당한다. 자격 확인, 발언의 정확한 의미, 연구와의 일치, 의료·광고 표현, 임베드·재사용 권리는 자동 승인하지 않는다. GitHub Actions가 수집한 항목은 반드시 PENDING_REVIEW로 남긴다.

## 8. 사업자용 감리 우선순위 보드

`GABA_VIDEO_TRIAGE.md`는 제목과 수집 가능한 공개 텍스트에서 질환·치료, 약물 대체·비교, 효과·안전성 단정, 섭취·상업성 신호를 찾아 사람이 먼저 볼 순서를 제안한다. 이 신호는 영상의 권위·근거·권리·효능을 판정하지 않으며, 자동 공개·자동 배제를 의미하지 않는다.

- `SCIENCE/MEDICAL 우선`: 일반 GABA 생리와 질환·약물·효과·안전성 주장을 먼저 분리한다.
- `SCIENCE/MEDICAL + RIGHTS`: 섭취·상업성 표현이 있어 과학·의료와 이해관계·사용권을 함께 확인한다.
- `VIDEO 우선`: 원문·자막·화자·실제 Shorts 형식을 먼저 확인한다.
- 최종 판정은 사람의 원문 확인 후 `PUBLISH_GENERAL`·`LIMITED_USE`·`HOLD`·`EXCLUDE`로 기록한다.
