# 제품 사실 증거 입력표

> **범위 밖 보관 문서:** 현재 공개 일반 GABA 교육본에는 제품 정보가 포함되지 않는다. 이 문서는 별도 제품 프로젝트에서만 사용한다.

`EVD-01` 제품 게이트를 위한 입력 양식이다. 판매처 페이지의 현재 노출 내용이나 과거 자료만으로 승인하지 않으며, 최신 포장·로트 또는 제조사 승인 자료를 기준으로 제품 책임자와 근거·준법 리드가 함께 검토한다.

## 승인 규칙

- 자료의 원문과 공개 문구가 일치하는지 확인한다.
- 자료의 SKU·로트·최종 인쇄본 적용 범위를 확인한다.
- 섭취량·주의사항·안전성·상호작용은 제품 표시사항 확인만으로 효능이나 개인별 적합성을 보장하지 않는다.
- 자료가 불완전하거나 최신성이 확인되지 않으면 상태를 `HOLD`로 유지한다.
- 제품 책임자와 근거·준법 리드의 식별자·확인일·승인 범위가 모두 채워지기 전에는 공개 페이지 문구를 넓히지 않는다.
