# 공개용 GABA 퍼블리싱 TF 킥오프 입력 시트

> **범위 전환 안내:** 일반 GABA 교육 TF의 새 역할과 회의 입력은 [`GABA_EDUCATION_KICKOFF.md`](GABA_EDUCATION_KICKOFF.md)를 사용합니다. 이 시트는 제품·후기·판매 흐름을 포함하던 이전 TF의 레거시 입력 양식입니다.

이 문서는 역할 정의를 실제 TF 회의와 현장 검증으로 연결하기 위한 최소 입력 시트다. 담당자·백업·첫 회의·A/B/C 세션 진행자가 입력되기 전에는 기술 QA가 통과해도 정식 사업·준법 승인으로 올리지 않는다.

## AI 비서 위임 상태

| 항목 | 입력 |
| --- | --- |
| AI 운영 역할 | `AI-OPS` — Codex AI 비서 |
| 위임 범위 | 문서·카피·코드·QA·TF 업무 추적·권고안 작성 |
| 실행 권한 | 활성 — 저장소 작업과 기술 검증을 진행 |
| 인간 승인 필요 | 제품 사실·효능·준법·후기 권리·현장 세션·최종 배포 |
| 위임 문서 | [`AI_ASSISTANT_ASSIGNMENT.md`](AI_ASSISTANT_ASSIGNMENT.md) |

AI-OPS는 6개 핵심 인간 역할을 대신하지 않는다. 승인 근거가 없는 항목은 `HOLD`로 유지하고 사용자 또는 지정된 인간 담당자에게 결정 요청을 올린다.

## 먼저 입력할 6개 핵심 역할

첫 회의는 아래 역할이 모두 있어야 결정 회의로 기록한다. 한 사람이 여러 역할을 맡을 수 있지만, `PRODUCT`와 `EVIDENCE`의 승인 판단은 구현자·영업 진행자와 분리하는 것을 원칙으로 한다.

| ID | 역할 | 주 담당자 식별자 | 백업 식별자 | 결정권 확인 | 첫 산출물 |
| --- | --- | --- | --- | --- | --- |
| PM | TF 리드·PM |  |  |  | 첫 회의 안건·보류 기준 |
| SALES | 사업·영업 리드 |  |  |  | A/B/C 세션 진행 계획 |
| UX | 소비자 UX·카피 리드 |  |  |  | 카드별 1메시지·다음 행동 검토 |
| EVIDENCE | 근거·준법 리드 |  |  |  | 전체 광고 인상·금지 표현 검토 |
| PRODUCT | 제품 책임자·표시 승인자 |  |  |  | 최신 SKU·라벨·로트 대조 |
| QA | 릴리스 QA 리드 |  |  |  | 실기기·공개 배포 검증 계획 |

## 첫 회의와 현장 세션 입력

| 항목 | 입력 |
| --- | --- |
| 첫 30분 회의 날짜·시간 |  |
| 참석 역할 | PM / SALES / UX / EVIDENCE / PRODUCT / QA |
| 첫 회의 논점 ID | UX-01 / UX-02 / SALES-01 / REL-01 / EVD-01 / RIGHTS-01 |
| A 시나리오 설명자·관찰자 |  |
| B 시나리오 설명자·관찰자 |  |
| C 시나리오 설명자·관찰자 |  |
| 제품 사실 자료 제출자 |  |
| 후기 권리 자료 제출자 |  |
| iOS·Android 검증자 |  |

고객 이름·연락처·건강 상태·복용 약은 이 시트와 세션 기록에 적지 않는다. 담당자 식별자는 조직 내부에서 확인 가능한 최소 정보만 사용한다.

## 사용 순서

1. 이 시트의 6개 핵심 역할과 백업을 채운다.
2. 첫 회의 논점은 1~2개만 선택하고 [`TF_DISCUSSION_BOARD.md`](TF_DISCUSSION_BOARD.md)에 연결한다.
3. 회의에서 `적용 / 관찰 / HOLD` 중 하나를 결정하고 [`TF_REVIEW_LOG.md`](TF_REVIEW_LOG.md)에 남긴다.
4. 실제 A/B/C 세션 결과는 [`SALES_SESSION_VALIDATION.md`](SALES_SESSION_VALIDATION.md)에 먼저 기록한다.
5. 모든 핵심 역할과 세션 담당자가 입력된 뒤 [`TF_ROSTER.md`](TF_ROSTER.md)의 상태를 갱신한다.

아래 블록을 채워 주면 배정표에 반영할 수 있다. 내부 식별자만 사용해도 된다.

```text
첫 회의 날짜·시간:

B 설명자 / 관찰자:
C 설명자 / 관찰자:
```
