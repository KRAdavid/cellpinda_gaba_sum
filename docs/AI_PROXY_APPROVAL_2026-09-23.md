## AI-OPS 판단

현재 조건을 대조한 결과, 공개 소비자 안내를 **조건부로 유지·공개하는 것을 사용자 승인에 갈음해 승인**한다. 공개본은 제품·후기·판매 정보를 다루지 않고, 일반 GABA의 개념·기능·연구 읽는 기준을 1페이지 1메시지 흐름으로 보여준다. 영상은 승인 영상과 검토 후보를 분리하며, 국내 `PUBLISH_GENERAL` 영상은 현재 0건이다.

이 결정은 공개 교육본의 편집·기술 상태에 대한 대리 승인이지, 연구 결과나 영상 인물의 권위를 인정하는 결정이 아니다.

## 이번 결정으로 승인하는 범위

1. 소비자 공개 URL과 발표자·TF 운영 URL을 분리해 계속 운영한다.
2. 8장 일반 GABA 교육 흐름, `일반 GABA 연구` 표기, 연구 조건·한계와 제품 효능 비연결 문구를 현재 구조로 유지한다.
3. 사용자가 공유한 국내 Shorts는 `원문 확인 전 검토 후보`로만 페이지 안에서 소개한다. 후보 요약·인물 소개는 예비 정보로만 사용하고 권위·효능 근거로 표시하지 않는다.
4. 자동 수집 후보는 `PENDING_REVIEW`로 유지하고, 자동 공개는 0건으로 유지한다.
5. 일일 감리 문서·영상 DB·TF 운영 문서·QA 결과를 공개본과 별도 운영 자료로 계속 관리한다.
6. 현재 Pages 배포는 일반 GABA 교육 공개본의 기술·편집 범위에서 유지한다.

## 이 결정으로 승인하지 않는 범위

다음 항목은 사용자의 대리 위임이 있어도 AI-OPS가 승인 완료로 바꾸지 않는다.

- 과학·의학 담당자의 `HUMAN_REVIEWED` 또는 공개 문장 최종 승인
- 의사·과학자 등 영상 출연자의 자격, 발언의 정확성, 과학적 타당성
- 영상의 저작권·임베드·인용·재사용 권리
- `PUBLISH_GENERAL` 또는 `LIMITED_USE`로의 영상 상태 변경
- 일반 GABA 연구를 셀핀다 제품의 효능·안전성·상호작용으로 연결하는 표현
- 법률·광고·식품 표시·의료 준법 판단
- 실제 iOS·Android, VoiceOver·TalkBack, 소비자·사업자 A/B/C 현장 검증
- PM·SCIENCE·MEDICAL·VIDEO·RIGHTS·UX·QA의 실명 역할 배정
- GitHub Actions의 실제 `schedule` 실행 증거와 사람이 수행한 일일 감리
