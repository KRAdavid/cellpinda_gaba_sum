# 공개용 GABA 퍼블리싱 TF 결정·액션 대장

이 문서는 토론 보드·역할표·세션 양식에 흩어진 결정을 한 줄 단위로 추적하기 위한 운영 대장이다. 역할명이 있다고 실제 담당자가 배정된 것은 아니므로, 담당자 식별자·기한·증거 제출 위치가 비어 있는 항목은 완료로 표시하지 않는다.

## 사용 규칙

- 회의에서는 한 번에 1~2개 행만 결정한다.
- `READY FOR FIELD`는 화면과 관찰 기준이 준비됐다는 뜻이며, 현장 PASS가 아니다.
- 실제 담당자·백업·결정권이 정해지지 않은 행은 `미배정/HOLD`로 남긴다.
- 변경 전에는 현재 공개 URL·커밋·QA 결과를 `RELEASE_HANDOFF.md`에서 고정한다.
- 제품 효능·섭취량·안전성·상호작용·후기 권리는 기술 QA만으로 `PASS`로 바꾸지 않는다.

## 상태 정의

| 상태 | 의미 |
| --- | --- |
| `OPEN` | 질문·이견·필요 증거를 정리하는 중 |
| `READY FOR FIELD` | 현장 또는 실기기 검증을 바로 시작할 수 있음 |
| `IN TEST` | 지정된 세션·기기·자료 확인을 실행 중 |
| `DECIDED` | 적용·관찰·HOLD 중 하나를 결정했지만 종료 증거가 남음 |
| `VERIFIED` | 종료 조건의 증거가 모두 등록됨 |
| `HOLD` | 담당자·1차 자료·권리·실기기 등 외부 입력 전에는 진행할 수 없음 |

## 세션 KPI의 단일 기준

- 다음 행동 명확도는 A/B/C **각 세션 4점 이상(1~5점)**이어야 한다. 평균만으로 통과시키지 않는다.
- 무이탈 흐름은 의도하지 않은 외부 페이지를 먼저 열지 않고, 요청한 카드·패널·다음 행동까지 도달한 세션으로 센다.
- 고객용 링크 전달 성공률은 실제 링크를 공유한 세션만 분모로 하되, 공유한 링크는 100% 의도한 `card=N#story`에서 열리고 발표자 모드가 없어야 한다.
- P0는 외부 링크 선행 이탈, 연구→제품 효능 오해를 만드는 확정 문구, 잘못된 제품 사실, 개인정보·건강정보 기록을 포함하며 0건이어야 한다.

## 회의 후 갱신 형식

아래 한 줄을 `TF_REVIEW_LOG.md`에 먼저 남긴 뒤 이 대장의 상태·담당·다음 검토일을 갱신한다.

`문제 → 결정(적용/관찰/HOLD) → 변경 파일 → 검증 결과 → 담당자·제출일 → 종료 조건`

실명·연락처·고객 식별정보는 이 대장에 기록하지 않는다. 조직 내부에서 확인 가능한 최소 식별자만 사용한다.
