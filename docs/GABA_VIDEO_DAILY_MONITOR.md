# GABA 숏츠 일일 모니터링 운영

## 목적

현재 등록된 채널에서 제목에 가바·GABA가 직접 들어간 새 영상 후보를 매일 수집하고, 일반 GABA·수면·뇌·스트레스 검색어와 `의사 GABA 신경전달물질 Shorts`, `과학자 GABA 신경전달물질 Shorts` 권위 후보 검색어로 유사 콘텐츠를 보완 발견한다. 기존 영상과 중복을 확인한 뒤 검토 대기함에 쌓는다. RSS가 응답하지 않는 채널은 해당 채널의 Shorts 페이지를 보완 경로로 확인한다. 실제 Shorts 형식인지, 과학·의료·권리 감리와 공개 승인은 자동화하지 않는다.

제목·공개 설명에 의사·박사·교수·과학자·doctor·scientist 등의 표현이 있으면 `전문가 자격 확인 신호`를 붙이고, 권위 검색어에서 발견된 후보에는 `권위 후보 검색 발견`을 별도로 붙인다. 이는 독립적인 자격·실제 화자·원문 발언을 확인하기 위한 감리 단서일 뿐 권위 승인이나 과학적 타당성 판정이 아니다.

매일 등록 DB의 원문 URL도 별도로 확인한다. 링크가 HTTP 경고를 내더라도 영상의 권위·내용·권리를 자동 승인하거나 상태를 바꾸지 않으며, 일일 리포트와 발표자 스냅샷에 접근 확인 수·전체 수·경고 수만 기록한다.

영상 DB에 등록된 권위·연구 출처 URL도 원문 링크와 분리해 매일 접근 상태를 확인한다. 이 점검은 출처 링크가 열리는지만 기록하며, 인물 자격·실제 Shorts 화자 일치·연구 내용·과학적 타당성·권리·공개 승인을 자동으로 확인하지 않는다.

YouTube 원문은 제목·채널 메타데이터가 응답하는지도 별도로 확인한다. 이 점검은 제목·채널 존재 여부를 확인하는 운영 신호일 뿐, 영상 내용·화자 권위·과학적 타당성·권리를 승인하지 않는다.

등록 YouTube watch 페이지에 자막 트랙 안내가 있는지도 별도로 기록한다. 자막 트랙 발견은 자막 본문 확보·정확성·화자 확인을 뜻하지 않으며, 사람 검토 전 요약이나 공개 상태를 바꾸지 않는다.

자막 트랙이 발견된 영상은 자막 본문 요청 응답도 별도 확인한다. 본문 확인은 비어 있지 않은 JSON3 텍스트 응답이 있었는지만 뜻하며, YouTube의 HTTP 429·본문 형식 오류·접근 제한은 경고로 남긴다. 본문이 확인되어도 번역 정확성·발언 맥락·화자 권위·과학적 타당성·권리·공개 승인을 의미하지 않는다.

## 운영 흐름

~~~text
YouTube 채널 RSS/Shorts 페이지 + 키워드 검색 결과
        ↓ 매일 09:00 KST 후보·유사 콘텐츠 수집
docs/GABA_VIDEO_INBOX.md (PENDING_REVIEW)
        ↓ 제목 기반 주의 신호·첫 담당 제안
docs/GABA_VIDEO_TRIAGE.md (사업자용 감리 우선순위 보드)
        ↓ 실행 요약·채널 경고·오늘의 액션
docs/GABA_VIDEO_DAILY_REPORT.md
        ↓ VIDEO: 원문·자막·화자 확인
SCIENCE/MEDICAL: 주장·근거·의료 표현 감리
        ↓ RIGHTS: 임베드·링크·인용 확인
docs/GABA_VIDEO_DB.md 갱신
        ↓ 승인된 일반 설명만 공개 페이지에 반영
~~~

## 실행 방법

~~~bash
# 네트워크에서 후보만 확인하고 파일은 바꾸지 않음
pnpm run monitor:gaba-shorts

# 검토 대기함에 새 후보를 추가
pnpm run monitor:gaba-shorts:write
~~~

GitHub Actions는 .github/workflows/monitor-gaba-shorts.yml에서 매일 실행한다. 예약 실행이 멈추지 않도록 저장소의 Actions·Pages 권한과 기본 브랜치를 확인한다.

일일 리포트·스냅샷의 기준일은 실행 서버의 UTC가 아니라 `Asia/Seoul` 한국 시간으로 생성한다. 자정 전후 실행에서도 회의에서 사용하는 날짜와 문서 파일명이 하루 밀리지 않도록 하기 위한 기준이다.

감리 워크플로가 성공하면 `.github/workflows/deploy-pages.yml`의 `workflow_run` 경로가 Pages를 다시 빌드한다. 이 연결은 일일 리포트·감리 대기 수·발표자 스냅샷을 최신 공개 발표자 화면에 반영하기 위한 것이며, 새 후보를 소비자 공개 목록에 자동 추가하거나 `PUBLISH_GENERAL`로 승인하지 않는다.

수집 결과의 팀 토론과 승인·보류·배제 기록은 GABA_VIDEO_REVIEW_LOG.md에 남긴다. 자동 수집 후보를 공개 페이지로 옮길 때는 이 로그의 종료 조건을 모두 채운다.

매일 실행한 채널 성공률·경고·신규 후보·다음 15분 감리 순서는 `GABA_VIDEO_DAILY_REPORT.md`에 자동 기록하고, 같은 내용을 `docs/gaba-video-daily/`에 날짜별로 보관한다. 이 리포트는 공개 승인 자료가 아니며, 팀의 당일 검토 입력으로만 사용한다.

사업자는 `GABA_VIDEO_TRIAGE.md`에서 제목 기반 주의 신호가 있는 후보부터 열어볼 수 있다. 제품·브랜드 신호가 붙은 후보는 일반 GABA 교육 후보와 제품성 콘텐츠를 먼저 분리한 뒤 SCIENCE/MEDICAL·RIGHTS가 함께 확인한다. 분류는 감리 순서만 제안하므로, 영상의 권위·연구 결과·권리·공개 가능성을 대신 판정하지 않는다.

감리 우선순위 표에는 `권위 신호 구분` 열을 두어 `전문가 표현 감지 · 자격 미확인`과 `권위 검색 발견 · 자격 미확인`을 나눠 기록한다. 두 값 모두 실제 자격·화자·원문·권리 확인 전의 발견 단서이며 권위 승인 값이 아니다.

소비자 영상 UX 감리의 기준은 예전 카드 나열이 아니다. 현재 영상 한 편만 읽고, compact 인덱스나 이전·다음 이동으로 이어지며, 상세 감리 패널을 확인한 뒤 원문을 선택할 수 있는지 확인한다. 일일 리포트의 PM/UX 다음 행동도 이 구조를 기준으로 생성한다.

발표자용 영상 DB 감리 패널에는 검토 대기함에서 우선순위가 높은 후보 5건을 `오늘 먼저 검토할 후보`로 함께 표시한다. 각 후보에 첫 담당과 다음 감리 행동을 함께 표시해 VIDEO·SCIENCE/MEDICAL·RIGHTS 담당자가 바로 이어받을 수 있게 한다. 이 목록은 제목·공개 설명 기반의 업무 순서이며, 원문·자막·화자·권리 확인 전에는 공개 승인이나 과학적 근거로 사용하지 않는다.

각 후보의 `이 후보 감리 초안 시작`을 누르면 외부 리포트로 이동하지 않고 발표자 화면 안에서 담당자·역할·결정 초안·확인 타임코드·확인한 발언·자막 발췌·5개 확인 체크·팀 메모를 기록할 수 있다. 초안은 `cellpinda-gaba-monitor-review-draft-v1`로 브라우저에만 저장하며, 자동 후보의 `PENDING_REVIEW` 상태·공식 DB·공개 승인 수를 바꾸지 않는다. 회의에서는 후보별 `후보 감리 초안 복사`로 사람이 확인한 내용을 전달하고, 최종 판정은 원문·자막·화자·근거·권리 확인 후 DB와 일일 로그에 반영한다.

같은 패널의 `권위 후보 확인 전` 큐에는 권위 검색어로 발견됐거나 제목·설명에 전문가 자격 표현이 감지된 후보를 별도로 표시한다. 각 후보에 `전문가 표현 감지 · 자격 미확인` 또는 `권위 검색 발견 · 자격 미확인`을 구분해 표시하므로, 검색 결과를 실제 권위 확인 결과와 섞지 않는다. 두 신호 모두 권위 자료를 우선 찾기 위한 보조 단서이며, 실제 자격·화자·원문·자막·권리 검토 전에는 권위 영상으로 공개하지 않는다.

같은 상위 후보와 사람 검토 체크리스트는 `docs/gaba-video-daily/GABA_VIDEO_REVIEW_SESSION_YYYY-MM-DD.md`로 날짜별 보관한다. 등록 영상별 자막 트랙·본문 접근 결과는 `docs/gaba-video-daily/GABA_VIDEO_CAPTION_AUDIT_YYYY-MM-DD.md`로 함께 보관한다. 발표자 화면의 `오늘 리뷰 세션`과 `자막 감사 기록` 링크에서 팀 토론·원문 확인 문서를 열 수 있으며, 체크가 끝나도 영상 DB와 검토 로그에 최종 판정을 기록하기 전에는 공개 상태를 바꾸지 않는다.

## 자동 수집이 하지 않는 일

- 의사·과학자 자격을 자동 승인하지 않는다.
- 영상이 말하는 도움·효과·안전을 사실로 판정하지 않는다.
- 일반 GABA 연구를 제품 효능으로 연결하지 않는다.
- 검토 전 후보를 소비자용 페이지에 게시하지 않는다.
- 영상 파일을 다운로드하거나 재편집하지 않는다. 기본 사용 방식은 원문 링크 또는 허용된 YouTube 임베드다.
- 설명란에만 GABA가 등장하는 장편·무관 영상은 기본 자동 수집에서 제외한다. 필요하면 VIDEO 담당이 수동 후보로 등록한다.
- 키워드 검색 결과는 권위·화자·주장의 정확성을 보증하지 않는다. 검색 발견 후보는 채널 후보와 별도 출처로 기록하고 동일한 감리 게이트를 적용한다.

## 매일 확인할 운영 지표

| 지표 | 종료 기준 |
| --- | --- |
| 새 후보 수 | 새 영상 ID와 채널을 기록 |
| 자막 확인 수 | 원문 발언·타임코드가 등록됨 |
| 권위 확인 수 | 공식 원출처와 화자 자격이 연결됨 |
| 과학 감리 수 | 주장별 근거·한계가 기록됨 |
| 권리 확인 수 | 임베드·링크·인용 조건이 확인됨 |
| 등록 영상 원문 링크 | 원문 URL의 HTTP 접근 상태를 확인하고 경고 수를 기록 |
| 권위·연구 출처 링크 | 등록된 독립 출처 URL의 접근 상태와 경고 수를 기록하며, 자격·근거·권리·공개 승인은 별도 사람 검토로 유지 |
| 등록 YouTube 메타데이터 | YouTube 제목·채널 응답 상태를 확인하고 경고 수를 기록 |
| 등록 YouTube 자막 트랙 | watch 페이지의 자막 트랙 안내를 확인하고, 본문 확보와 분리해 경고 수를 기록 |
| 등록 YouTube 자막 본문 | 자막 본문 응답의 존재를 트랙 발견과 분리해 확인하고, HTTP·형식 경고 수를 기록 |
| 공개 승인 수 | PUBLISH_GENERAL로 판정됨 · LIMITED_USE는 공개 전 제한 사용 후보로 유지 |
| 보류·배제 수 | 사유와 재검토 조건이 남음 |

## 사업자 활용 방식

사업자용 화면에서는 승인된 영상만 오늘의 일반 GABA 설명 영상으로 선택해 별도 영상 요약 섹션과 상세 감리 패널에서 보여준다. 발표자는 영상 원문으로 보내기 전에 다음 세 문장을 사용할 수 있다.

1. 이 영상은 제품 광고가 아니라 GABA라는 성분의 일반 설명 자료입니다.
2. 영상의 주장과 일반 연구 결과는 각각 조건과 한계를 확인해야 합니다.
3. 이 내용만으로 특정 제품의 효능이나 개인의 복용 여부를 판단하지 않습니다.

원문보기 버튼은 새 탭 이탈을 기본 행동으로 두지 않고 현재 페이지의 영상 요약·상세 감리와 다음 메시지를 먼저 제공한다. 외부 링크는 내용을 읽은 뒤 선택하는 보조 경로로 유지한다.
