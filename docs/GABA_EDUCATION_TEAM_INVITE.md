# 일반 GABA 교육 TF 초대·업무 배정 패킷

이 문서는 기존 셀핀다 제품 배포 TF와 분리된 **일반 GABA 교육 TF**에 사람을 초대하고 첫 검토 업무를 배정하기 위한 전달본이다.

공개 페이지의 범위는 GABA의 이름·일반 기능·일반 연구·감리된 영상 소개다. 제품명·가격·구성·섭취량·후기·판매 링크·제품 효능은 이 TF의 공개 범위가 아니다.

## 첫 회의에서 확정할 것

1. 7개 핵심 역할의 주 담당자와 백업
2. 첫 번째로 사람 검토할 과학 출처 5건
3. 첫 번째로 원문을 확인할 국내 영상 후보 3건
4. 매일 모니터 후보를 검토할 담당 순서와 다음 회의일
5. A/B/C 사업자 설명 세션의 진행자·관찰자·기기

역할 이름이나 회의 시간이 입력되기 전에는 `HOLD`로 유지한다. AI-OPS는 초안·수집·QA·회의 자료를 준비하지만 과학·의학·권리·현장·최종 공개 승인을 대신하지 않는다.

## 초대 메시지

> 일반 소비자가 GABA를 처음 접해도 3분 안에 이름·일반 기능·연구의 한계를 이해하도록 돕는 공개 교육 TF입니다. 제품 판매 자료가 아니라 과학·영상·UX를 함께 감리하는 작업입니다. 첫 회의에서는 역할을 배정하고, 과학 출처와 영상 후보를 실제 원문 기준으로 나눠 검토합니다. 아래 회신 양식에 참석 가능 시간과 맡을 수 있는 역할을 적어 주세요.

## 역할과 첫 산출물

| 역할 | 첫 담당 업무 | 첫 산출물 | 종료 조건 |
| --- | --- | --- | --- |
| PM | 범위·우선순위·회의 결정 관리 | 결정할 것·보류할 것·다음 회의일 | 담당자·기한·종료 조건 연결 |

## 첫 검토 업무 배정안

### 과학 출처 5건

`SRC-01~SRC-05`를 SCIENCE 주 담당자가 먼저 읽고 MEDICAL 담당자가 오해 가능성을 교차 확인한다. 일반 GABA 연구를 특정 제품의 효능·안전성·섭취량으로 확장하지 않는다.

### 영상 후보 3건

첫 회의의 영상 검토는 아래 국내 후보 중 3건으로 시작한다.

- `VID-02` 국가과학기술연구회 신경전달물질 개론
- `VID-03` Braintube GABA 영상
- `VID-04` 서울대병원 이승훈 교수 영상

각 영상에서 반드시 남길 항목은 다음과 같다.

1. 무엇을 어떻게 소개했는가
2. 해당 영상 인물은 누구인가
3. 확인한 타임코드와 실제 발언
4. 일반 GABA 기능과 제품·증상·섭취 주장의 분리
5. 원문 링크·임베드·인용 가능 범위

원문·자막·화자·근거·권리를 모두 확인하기 전에는 `HOLD`를 유지한다.

### 매일 모니터 후보

자동 수집 후보는 `PENDING_REVIEW`로만 받는다. 제목에 의사·박사·과학자가 포함되어도 자격 승인으로 보지 않는다. VIDEO가 원문을 확인하고 SCIENCE/MEDICAL·RIGHTS가 이어받을 후보를 매일 5건까지 회의 큐에 올린다.

## 첫 회의 45분

| 시간 | 진행 | 산출물 |
| --- | --- | --- |
| 0~5분 | 공개 URL·범위·현재 HOLD 확인 | 오늘 결정할 논점 1~2개 |
| 5~12분 | 8장 소비자 흐름 확인 | 첫 화면 혼선 1건 |
| 12~20분 | SRC-01~05 연구 경계 검토 | 공개·보류 문장 |
| 20~32분 | VID-02~04 원문 감리 순서 결정 | 영상별 담당·타임코드 목표 |
| 32~39분 | 일일 모니터·제품성 격리 확인 | 매일 검토 담당 순서 |
| 39~45분 | A/B/C·다음 회의 확정 | 담당자·기한·종료 조건 |

## 회신 양식

```text
이름 또는 내부 식별자:
희망 역할 / 백업 역할:
참석 가능 시간:
첫 검토 가능 출처(SRC-01~SRC-05):
첫 검토 가능 영상(VID-02~VID-04):
A/B/C 세션 진행자 또는 관찰자 가능 여부:
확인 가능한 모바일 기기:
다음 회의 가능일:
```

## 회의 후 기록 위치

- 역할·첫 회의 입력: `GABA_EDUCATION_KICKOFF.md`, `GABA_EDUCATION_TF.md`
- 과학 출처 감리: `GABA_SOURCE_REGISTER.md`
- 영상별 감리: `GABA_VIDEO_DB.md`, `GABA_VIDEO_REVIEW_LOG.md`
- 일일 후보: `GABA_VIDEO_DAILY_REPORT.md`, `GABA_VIDEO_TRIAGE.md`
- 공식 결정: `GABA_EDUCATION_DECISION_REGISTER.md`

기술 준비 상태는 `pnpm run qa:education-tf`로 확인한다. 이 명령이 통과해도 실제 사람 역할 배정·사람 감리·현장 세션·공개 승인은 자동 완료되지 않는다.
