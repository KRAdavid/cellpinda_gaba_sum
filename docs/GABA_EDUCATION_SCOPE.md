# 일반 GABA 교육 페이지 범위 선언

## 이번 프로젝트의 목적

GABA를 처음 접하는 일반 소비자가 짧은 시간 안에 다음 세 가지를 이해하도록 돕는 과학 교육용 페이지를 만든다.

1. GABA가 무엇인지
2. 인체와 뇌에서 어떤 역할로 알려져 있는지
3. 연구 결과를 어디까지 이해해야 하는지

이 페이지는 기존 셀핀다 GABA 공식 배포 사이트 및 제품 판매 페이지와 구분되는 **일반 GABA 소개 자료**다.

## 포함 범위

- GABA의 이름·분자·신경전달물질에 대한 일반 설명
- 흥분과 억제, 신호 조절을 이해하기 위한 쉬운 비유
- 수면·스트레스·뇌 기능과 관련된 일반 연구의 질문·조건·한계
- 과학자·의사·공공기관 등 권위 있는 설명 영상의 큐레이션
- 연구 출처, 영상 출처, 공개일, 발언 구간, 자막·대본
- 모바일 숏츠·릴스처럼 읽을 수 있는 세로 진행선과 한 장면 한 메시지 구성

## 제외 범위

- 셀핀다 제품명·SKU·가격·구성·섭취량·구매 링크
- 제품 특허·고순도·고함량·발효공정·안전성 홍보
- 제품 후기·구매자 경험·판매자 설명
- GABA 보충제가 스트레스·수면·질환을 개선한다는 확정 표현
- 혈중·뇌내 GABA 수치 부족을 일반 소비자에게 가정하는 표현
- 의약품 치료, 진단, 복용 중단 또는 개인별 섭취 지시

## 콘텐츠 원칙

- 한 장면에 한 메시지만 두고, 소비자 화면은 카드 격자나 카드 넘김 UI 대신 장면 목차·중앙 읽기 흐름으로 구성한다.
- 일상 장면으로 시작하되, 질환이나 결핍을 진단하지 않는다.
- `일반 GABA 연구`라는 표기를 연구 패널과 영상 요약 섹션에 고정한다.
- 연구 결과와 GABA 일반 기능 설명을 제품 효능으로 연결하지 않는다.
- 과학적 주장에는 원문 링크와 연구 한계를 함께 표시한다.
- 영상은 권위자의 말이라는 이유만으로 사실을 확정하지 않고, 원출처와 발언 구간을 기록한다.
- 소비자 피드와 영상 소개를 섞지 않고, 피드 뒤 별도 영상 섹션에서 히어로 샷·요약·인물 소개·공식 원문 링크를 제공한다. 상세 감리는 인페이지 패널로 이어간다.

## 권장 학습 흐름

`일상에서 생기는 변화 → 뇌가 쉬는 시간 → GABA란 무엇인지 → GABA가 하는 일 → 일반 GABA 연구를 읽는 기준 → 한 문장 정리 → 별도 영상 검토 후보·승인 영상 요약·원문 링크`

| 최종 검토 | 과학 근거 검토자와 의학 검토자 확인 후 공개 |

## 2026-09-22 소비자 리더 전면 개편

기존 카드 중심 표현과 진입 문구를 제거하고, `GABA를 모르는 사람도 3분 안에 이해하는 흐름`이라는 에디토리얼 리더로 첫 화면을 개편했다. 모바일은 첫 장면 CTA·뇌 신호 시각·8개 진행선·세로 읽기를 한 흐름으로 보여 주고, 데스크톱은 장면 목차·중앙 본문·현재 장면/연구 경계를 나란히 둔다. 외부 원문은 정보 패널을 먼저 거친 뒤 선택하며 영상은 본문 뒤 별도 섹션에서 한 편씩 확인한다. 결정은 **카드 UI 제거·한 메시지 읽기 흐름 기술 PASS / 실제 iOS·Android와 A/B/C 사업자 세션 검증 HOLD**다.
