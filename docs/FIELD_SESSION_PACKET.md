## 설명자 고정 진행

### A. 전체 이야기

`일상 상태 → 여유가 안 생기는 날 → 생각 과부하 → 적극적인 휴식 → GABA 성분 이름 → 일반 GABA 연구 → 제품 정보 → 활용 TIP → 생활 루틴 → 후기·마무리`

권장 연결 문장: “먼저 일상에서 느낄 수 있는 상태와 휴식을 보고, 그다음 GABA 일반정보와 연구, 제품 정보를 나누어 확인하겠습니다.”

관찰 포인트: 05번 성분 이름이 제품 효능으로 이어진다고 오해하지 않는지, 연구 패널에서 제품 경계를 확인하는지, 외부 자료를 먼저 열지 않고 다음 카드로 이어가는지.

### B. 제품 정보 우선

07번 제품 카드에서 제품명·구성·식품 유형의 공개 안내 범위만 보여 준다. 최신 포장 표시사항을 확인하기 전 섭취량·혼합 방법·주의사항·안전성·상호작용을 확정하지 않는다. 패널 설명 후 `이 카드 고객용 링크 복사`를 사용한다면 공유 링크가 고객 모드로 열리는지 확인한다.

권장 연결 문장: “제품 정보는 공개 안내 범위로 먼저 보고, 섭취법과 주의사항은 최신 포장 표시를 다시 확인하겠습니다.”

관찰 포인트: 고객이 제품 안내와 구매·외부 자료를 구분하는지, 발표자 모드가 전달되지 않는지, 다음 카드가 보조 행동으로 명확한지.

### C. 근거 질문 대응

06번 연구 카드에서 연구 패널을 먼저 열고, 일반 GABA 연구라는 범위와 제한적 결론을 보여 준다. 질문에 답한 뒤 `다음 카드로 계속 보기`로 제품 카드로 이어간다.

권장 보류 문장: “이 연구는 일반 GABA 섭취를 살펴본 자료이고, 셀핀다 제품의 동일 제형·섭취량 효능을 직접 입증한 자료는 아닙니다.”

관찰 포인트: 수면·스트레스·병용·섭취량 질문에 제품 효능이나 상호작용 없음으로 답하지 않는지, 답변 복사 후 발표 흐름이 유지되는지.

## 관찰자 판정 기준

### 다음 행동 명확도 1~5점

| 점수 | 관찰 기준 |
| ---: | --- |
| 1 | 무엇을 봐야 하는지 모르고 설명자의 재지시가 반복됨 |
| 2 | 선택지는 보지만 다음 카드·패널·외부 자료의 차이를 혼동함 |
| 3 | 설명을 들은 뒤 다음 행동을 선택함 |
| 4 | 짧은 설명만으로 `다음 카드`·패널·필요한 보조 자료 중 하나를 정확히 선택함 |
| 5 | 별도 재지시 없이 의도한 다음 행동을 선택하고 흐름을 설명할 수 있음 |

A/B/C **각 세션 4점 이상**이어야 현장 기준을 충족한다. 평균 점수만으로 통과시키지 않는다.

### 무이탈 흐름

`통과`: 고객 요청 없이 외부 원문·스마트스토어·후기 페이지를 먼저 열지 않고, 현재 페이지의 패널·다음 카드·요청한 고객용 카드 링크까지 도달함.

`실패`: 설명자가 외부 링크를 먼저 열어 카드 흐름을 끊음, 외부 페이지가 의도하지 않은 기본 경로가 됨, 또는 고객용 링크에 발표자 모드가 남음. 발생 카드·행동·재현 단계를 기록한다.

### P0 판정

- 일반 GABA 연구를 셀핀다 제품 효능의 직접 근거로 확정함
- 최신 승인 전 제품 사실·섭취량·안전성·상호작용을 확정함
- 외부 링크·잘못된 카드·발표자 메모가 고객에게 의도치 않게 전달됨
- 고객 개인정보·건강정보·복용 약을 기록함

P0가 1건이라도 있으면 해당 세션은 통과로 계산하지 않고, 페이지나 진행 문구를 임의 수정하지 않은 채 `TF_REVIEW_LOG.md`에 재현 내용을 남긴다.
