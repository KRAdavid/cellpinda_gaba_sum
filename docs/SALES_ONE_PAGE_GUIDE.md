# 사업자용 GABA 한 페이지 사용 가이드

고객에게 공개 페이지를 보여줄 때 바로 옆에 두고 사용하는 요약본이다. 제품 효능·섭취량·안전성·상호작용을 확정하는 문서가 아니며, 상세 기준은 [`SALES_WALKTHROUGH.md`](SALES_WALKTHROUGH.md)와 [`SALES_SESSION_VALIDATION.md`](SALES_SESSION_VALIDATION.md)를 따른다.

## 시작 링크

| 상황 | 링크 | 사용 목적 |
| --- | --- | --- |
| 일반 소비자 안내 | <https://kradavid.github.io/cellpinda_gaba_sum/> | 고객이 직접 한 장씩 확인 |
| 전체 발표 | <https://kradavid.github.io/cellpinda_gaba_sum/?mode=presenter&card=1#story> | 01번부터 발표자 모드로 진행 |
| 제품 문의 우선 | <https://kradavid.github.io/cellpinda_gaba_sum/?mode=presenter&card=7#story> | 제품 질문이 먼저 나왔을 때 |

## 진행 순서

시간이 충분하면 전체 흐름을 유지한다.

`01 일상 상태 → 02 여유가 안 생기는 날 → 03 생각 과부하 → 04 적극적인 휴식 → 05 GABA 성분 이름 → 06 일반 GABA 연구 → 07 제품 정보 → 08 활용 TIP → 09 생활 루틴 → 10 후기 → 11 마무리`

시간이 제한되면 핵심 흐름으로 진행하되, 고객이 섭취법·조합·저녁 루틴을 질문하면 08·09번 카드로 돌아간다.

`01 → 04 → 05 → 06 → 07 → 10 → 11`

## 화면에서 사용할 행동

1. 소비자 화면에서는 `다음 카드`를 눌러 이어가거나 카드를 좌우로 민다.
2. 연구·제품·후기는 카드 안의 패널을 먼저 읽는다.
3. 패널에서는 `다음 카드`로 현재 페이지 흐름을 이어간다.
4. 원문·스마트스토어는 고객이 요청할 때만 `외부 자료는 필요할 때만 확인`을 열어 선택한다.
5. 사업자 발표에서는 `다음 설명`, `발표자용 진행 포인트`, `자주 묻는 질문에 답하기`, `제품부터 설명`을 사용한다.
6. 카드 공유가 필요하면 고객용 링크인지, `발표자 모드 제외`가 표시되는지 확인한다.

## 핵심 설명 문장

- “GABA는 감마아미노부티르산을 줄여 부르는 성분 이름입니다. 제품 정보와 분리해 일반정보부터 확인하겠습니다.”
- “앞의 자료는 일반 GABA 연구이며, 셀핀다 제품의 동일 제형·섭취량 효능을 직접 입증하는 자료는 아닙니다.”
- “제품명·구성·식품 유형은 공개 안내 범위로 보고, 섭취법과 주의사항은 최신 포장 표시를 다시 확인하겠습니다.”
- “후기는 개인 경험이므로 연구자료나 모든 사람에게 같은 결과가 나타난다는 뜻은 아닙니다.”

## 질문이 나오면

발표 모드의 `자주 묻는 질문에 답하기`를 열어 승인된 보류 문장을 확인하고, 질문에 답한 뒤 현재 카드 흐름으로 돌아간다.

| 고객 질문 | 화면에서의 대응 |
| --- | --- |
| 수면·스트레스에 도움이 되나요? | 일반 연구의 조건과 제한을 먼저 보여주고 제품 효능으로 확정하지 않는다. |
| 하루에 몇 포 먹나요? | 연구 수치를 제품 섭취량으로 바꾸지 않고 최신 포장 표시를 확인한다. |
| 다른 영양제·허브티와 같이 먹어도 되나요? | `상호작용 없음`이라고 단정하지 않고 제품 표시사항과 개인 상황을 전문가에게 확인하도록 안내한다. |
| 후기를 광고에 써도 되나요? | 원문·이미지 사용권, 작성 맥락, 경제적 이해관계를 확인하기 전에는 재게시하지 않는다. |

## 상담 종료

마지막에는 구매를 압박하지 않고 고객이 원하는 다음 행동을 고르게 한다.

- 일반 연구를 더 확인하기
- 제품 정보 확인하기
- 구매자 후기 확인하기
- 오늘 실천할 작은 휴식 정하기

실제 A/B/C 사업자 세션, 최신 제품 라벨·로트, 후기 권리, iOS·Android 확인이 완료되기 전에는 최종 사업·준법 승인으로 표시하지 않는다.
